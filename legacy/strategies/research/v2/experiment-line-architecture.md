# 实验线架构设计方案（v6）—— 完整映射 + 成果吸收 + 审阅修订

> 定位：实验线 = 生产线的完整映射实例（测试版本）；前瞻实验在实验线整链做，
> 验证后以"环节段"为单位整段搬回生产线。
> v6 = v5 + 理论审阅修订（D1/D2/D3/D4/D5/D6/D7 拍板结果）。
> 状态：方案阶段，未实现。

---

## 0. 架构目标

实验线是生产线的同构镜像（staging）。两线共享同一管道蓝图与环节契约，差异只在
"当前启用的配置集合"。V1-V8 历史成果按四类归位；机制为第一实体、策略为实例；
一切可信度输出必须三层合成。

## 1. 设计原则（v6，含审阅修订）

- **P1 机制是第一实体，策略是实例**（审阅 D1 采纳；依据 04-R2、01-L1/L2）。
  系统围绕"收益来源机制"组织；策略只是机制在特定品种、状态、参数下的实例化；
  实例退役 ≠ 机制死亡。
- **P2 同构镜像**：实验线是生产线的完整映射实例，不是组件；两线共享同一管道蓝图。
- **P3 环节对**：每环节 stable/candidate 双配置，实验只动 candidate。
- **P4 回放基线**：实验线能整链回放 stable，复现生产产出（01-L3/L4）。
- **P5 整链实验 + 便宜筛前置**（审阅 D2 采纳；依据 01-L3）：
  一切前瞻实验都在完整管道内做，不做旁路；但 candidate 在进入整链回放之前，
  必须先通过 **G1 机制命题检验**（最便宜的统计检验），G1 不过不进整链。
- **P6 严格整段搬迁**（审阅 D3 采纳；依据 04-R2、01-L4）：
  promote 单位 = 完整环节段，环节内一切参数随段版本走，**不设热更新白名单**；
  需要快速更新时走"小段版本"快速 promote，不允许绕过版本。
- **P7 实验隔离**：实验线产物永不直接进入生产报告（01-L3/L4）。
- **P8 成果归位**：任何历史成果必须归入四类之一——生产 stable / 环节 candidate /
  镜像基础设施 / 反例；归不进去的即退役。
- **P9 可信度三层合成契约**（审阅 D6 采纳；依据 04-R2、01-L3）：
  任何面向人或生产的"可信度"输出，必须 = 族级证据 × 实例状态匹配 × 实现保真，
  三者缺一时可信度必须降档并标明缺失项；禁止单层（如 FinCoT 自报）代替。
  生产报告现状（自报 confidence）标记为"未达标现状"，在报告环节 candidate
  promote 前不得改称"已验证可信度"。

## 2. 第一实体：机制（Mechanism）与策略实例

### 2.1 机制条目（概念字段）

| 字段 | 内容 |
|------|------|
| id / name / family | family ∈ {carry, value, momentum, volatility, liquidity, behavioral-friction}（04-R1/R2） |
| theoryRef | theory-base 报告编号 + 章节 + 命题（强制） |
| proposition | 可证伪 H0/H1 |
| whyItWorks | 机制逻辑 + 为什么没被套利掉（04-R2 四问） |
| applicableStates | 状态变量与取值域（趋势态/库存态/波动态/政策窗/交割距离） |
| timeScale | 半衰期或持有期范围（02：半衰期先于持有期） |
| invalidation | 结构性失效 vs 状态性失灵（04-R3） |
| evidenceLedger | 指向证据账本条目 |
| lifecycle | candidate → probing → state_validated → retired（状态级） |

### 2.2 策略实例（Strategy Instance）

| 字段 | 内容 |
|------|------|
| mechanismId | 绑定机制（P1 强制） |
| universe / dataContract | 品种集与数据需求（数据契约按机制需求注册） |
| params | 参数（少、强度制优先，03-S3/S4） |
| fidelity | 实现保真级别（23 F-A..F-H 结果） |
| instanceEvidence | 该实例的实验证据 |
| lifecycle | derived → backtested → validated → deprecated |

## 3. 架构总图（同 v5，略图）

```
                 ┌──────────────── 管道蓝图（唯一架构） ────────────────┐
                 │  数据获取 → 筛选 → FinCoT 推理 → 概率 → 策略适配 → 报告 │
                 └─────────────────────────────────────────────────────┘
        stable 配置                                        candidate 配置
                 │                                                │
     ┌───────────▼────────────┐                  ┌────────────────▼───────────────┐
     │ 生产线（production）    │◄── promote ──────│ 实验线（experiment / staging）  │
     │ 每日自动跑 stable      │   整段搬回         │ 回放 stable 建立基线            │
     └────────────────────────┘                  │ G1 便宜筛 → 整链回放 → 影子      │
                                                 └────────────────────────────────┘
```

## 4. 前瞻实验生命周期（v6，含 D2/D4/D7 修订）

```
G1 命题检验（前置便宜筛，D7 数据纪律在此执行）
   → register（candidate 配置 + 机制命题 + 判决规则 + 证据要求；判决规则写死）
   → replay（回放 stable 基线 → 回放 candidate → 差异）
   → shadow（影子并行；观察期不预固定——D4 拍板 B）
        · 每固定周期人工 review，review 必须生成证据快照 + 归因记录，快照不可事后修改
        · promote 仍必须满足 register 时写死的判决规则（规则不变，观察时长灵活）
   → review（按预注册规则判决：promote / revert / 继续观察）
   → promote（严格整段搬迁，P6）
```

**D7 硬前置**（写入 G1 门槛）：
- 任何用历史基线做可信度标定的数据，必须先逐条 PIT 冻结校验；
- 任何多参数历史成果（如 V6 安全门）回归筛选/适配环节前，必须先做参数敏感性检验。

## 5. V1-V8 成果归位（同 v5 §3，新增 D5/D6 落位）

归位表沿用 v5 §3（数据获取/筛选/FinCoT/概率/策略适配/报告/方法论），v6 补充两处：

- **D5 模板拆分**：V7 蓝图的"搬迁流程"仍作 promote 模板（学"怎么搬"）；
  环节**内容模板**另立为"机制实例模板"（P1 机制条目 + 实例字段），V7 蓝图
  不作为内容模板（不学"搬什么"）。
- **D6 可信度契约**：signal-quality-baseline 全系列在 PIT 校验通过后，作为
  报告环节 candidate（三层可信度模型）的标定数据；生产报告现状标记为
  "未达标现状"，promote 前不得称已验证可信度。

## 6. 资产处置（沿用 v5 §7）

同 v5：GA 系列为数据层/数据 candidate；harness 为策略适配环节验证工具；
机制探针为 G1 工具；v2 八条目转为机制实例档案（P1 的实例层）；
v1 规则库为生产 stable 现状，待策略适配 candidate 通过后整体替换；
theory-base 为机制注册理论源；23/24 为判决纪律（24 覆盖单轮，影子统计纪律
标注为理论空白，暂以"预注册判决规则 + 定期 review 快照"工程纪律代管）。

## 7. 架构决策记录（ADR）

- AD-1 **机制是第一实体，策略是实例**（P1，审阅 D1）；
- AD-2 实验线是生产线的完整映射实例（P2）；
- AD-3 每环节 stable/candidate 双配置（P3）；
- AD-4 一切前瞻实验必须回放+影子，不做旁路（P5 前半）；
- AD-5 **G1 命题检验是整链实验的前置门槛**（P5 后半，审阅 D2）；
- AD-6 **promote 严格整段，无热更新白名单；快速更新走小段版本**（P6，审阅 D3）；
- AD-7 **影子观察期不预固定；判决规则在 register 写死；定期 review 生成不可改证据快照**（审阅 D4 拍板 B）；
- AD-8 实验线产物永不直接进入生产报告（P7）；
- AD-9 历史成果四类归位，不归位即退役（P8）；
- AD-10 **可信度三层合成是强制契约，缺一层即降档并标注**（P9，审阅 D6）；
- AD-11 标定数据 PIT 校验与多参数成果敏感性检验是 G1 硬前置（审阅 D7）；
- AD-12 **V7 只作搬迁流程模板；内容模板=机制实例模板**（审阅 D5）；
- AD-13 禁止模式：旁路实验不绑定公式（V9 教训）、后置定价层（pricing-layer-v8 教训）。
