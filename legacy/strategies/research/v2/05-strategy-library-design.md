## 0. 设计目标与合成决策

### 0.1 目标与输入

把 t1/t2/t3 的 30 条候选调研与 t4 的 38 条数据契约合成为一个**可落地、可证伪、可冻结**的策略库 v2 核心设计：

1. **数量控制**：核心策略 8 条（4–8 上限内），其余进入候补池/剔除清单，不默认入库。
2. **强绑定**：每条核心策略是不可拆分的"理论→模型→策略"单元，五段完整，缺一段即不合格。
3. **定价封闭**：止损/目标/仓位只由本条目的市场模型方程导出；FinCoT 输出只可作方向候选触发器、否决过滤器与事件识别，不产生任何数值定价。
4. **数据真实**：每条目的数据契约引用 t4 契约键与全局前置动作（GA-1..GA-6），数据未就绪不可入库。
5. **参数纪律**：参数有来源、初值待标定、证伪测试通过后冻结；冻结后修改 = 新策略。

### 1.2 策略条目状态机（t6 编纂时写入 manifest）

```
designed → in_validation → validated → frozen → (live)
              │                │          │
              ▼                ▼          ▼
          (证伪失败)      (证伪失败)   suspended ──结构事件重评估──→ re_evaluation → validated/frozen
              └──────────→ retired      │
                                        └─连续失效/停用规则触发──→ retired
```

- `designed`：五段完整、参数待标定（t6 产出物即此状态）。
- `in_validation`：数据契约满足（GA 完成）、回测+证伪测试执行中。
- `validated`：证伪测试全部通过，参数冻结，写入冻结版本号。
- `frozen`：入库执行状态；修改任何冻结参数 → 新 ID 新条目，回到 `designed`。
- `suspended`：停用规则触发（连续窗口失效、样本不足自停、理论级证伪）——停止新开仓，存量按失效退出。
- `retired`：永久退出，留档防复活。

### 3.1 TR-01 趋势延续（状态过滤版）【交易系统】

**来源**：t3 §1。**证据级**：A−（样本内正向 + 国内外文献，缺样本外验证）。

**① 核心理论（可证伪命题）**
- H0：突破 + 量能确认子样本与"无确认突破"子样本的扣成本收益无差异（信息确认机制无效）。
- H1：在上升趋势状态 U 中 `E[r_{t+h} | sign(r_{t−L,t})=+, s_t=U] > 0`，且该优势随 h 增大而衰减（动量半衰期）。
- 机制（为什么持续）：信息扩散缓慢（反应不足，价格逐步吸收基本面变化）+ 正反馈与资本再配置（趋势资金自我强化）+ 风险转移（套保盘让渡风险溢价）。三类机制仅在"状态 U 得到量仓确认"时最强。
- 中国证据：时间序列动量在中国商品期货显著存在（Economic Modelling 2023）；仓库内部 EMA20 趋势 + 突破为样本内唯一正向验证（`SIMPLE-MOMENTUM-RESULTS.md`）。

**② 市场模型（状态变量 + 公式 + 条件分布）**
- 状态变量：`s_t ∈ {U(up), D(down), C(chop)}`——对齐 `close_t > MA20_t 且 > MA60_t`（空头镜像）+ 斜率 `g_t = (EMA20_t − EMA20_{t−5})/(5·EMA20_{t−5})`，`g_t ≥ +0.3%/日` 为 U 态；动量强度 `m_t = r_{t−20,t}`。
- 条件分布：`r_{t+h} | s_t=U ~ N(μ_U·f(h), σ_t·√h)`，`f(h)` 单调衰减、`f(h)→0`，半衰期 5–10 个交易日；`μ_U ∝ m_t`。
- 状态转移：`P(s_{t+1}=U | s_t=U) = q_UU`（高）；失效事件 `F_t`：收盘跌回突破位下方 0.5×ATR5，或放量（量比 ≥1.5）收盘跌破 `MA20_t − 0.5×ATR5`。`F_t` 出现 → `s_t` 转出 U = **理论失效点**。
- 信息确认：`1{close_t > max(high_{t−20..t−1})} × 1{量比_t ≥ 1.2}` = **模型确认区**（突破 + 量能 = 信息进入市场的证据）。

**③ 策略（定价全部由②导出）**

| 要素 | 规则 | 模型溯源（入场=确认区/止损=失效点/目标=衰减点/仓位=强度） |
|------|------|------|
| 方向 | 多空对称；空头距涨停 < 1×ATR5 禁开（逼仓） | 模型不含方向预测项，只做状态跟随 |
| 入场 | U 态 ∧ 收盘突破 20 日高/低 ∧ 量比 ≥1.2 → T+1 开盘；跳空 > 0.5×ATR5 放弃 | 确认区触发 |

| 失效退出 | 收盘触发 F_t → 次日开盘离场；连续 2 日量比 < 0.8（动能衰竭）→ 次日离场 | F_t |
| 目标 T1 | 2R 平 50% | edge 半衰期前锁定（f(h) 衰减） |
| 目标 T2 | 3R 或 3d p95 上/下沿 [cap-6：锥=Yang-Zhang 波动投影，provenance=probability.json]，先到者；余仓 2×ATR5 移动止损 | f(h) 衰减至成本以下 |

### 3.2 TR-03 趋势回踩续势（趋势 + OU 噪声分解）【交易系统】

**来源**：t3 §3。**证据级**：B（经典文献 + 行业通行，仓库未直接回测）。

**① 核心理论（可证伪命题）**
- H0："回踩 + 反转确认"子样本与"回踩无确认"子样本收益无差异（噪声耗尽确认无效）。
- H1：U 态中价格回踩至 MA20 带（噪声分量 `x_t` 显著为负）后出现反转确认 K 线时 `E[r_{t+h}] > 0`，优势来自噪声回归项 `θ·|x_t|`，随 `x_t→0` 耗尽。
- 机制：趋势由基本面/资金流驱动（慢变量 c_t），短期偏离由流动性冲击造成（快变量 x_t、均值回归）；回踩 = 趋势跟随者成本最优区，确认 K = 噪声耗尽、趋势恢复支配。edge 主要由 `θ·|x_t|` 贡献 → 止损距离必须 ≤1.5R，否则噪声 edge 覆盖不了成本。
- 证据：Edwards & Magee 趋势线回踩；Raschke & Connors (1996) "Holy Grail" 形态。

**② 市场模型**
- 分解模型：`p_t = c_t + x_t`；c_t 为趋势分量（U 态下带漂移 μ_c 的随机游走）；x_t 为 OU 噪声：`dx_t = −θ·x_t dt + σ·dW_t`，`E[x_{t+h}|x_t] = x_t·e^{−θh}`。
- 回踩条件（多）：`low_t ≤ MA20_t + 0.25×ATR5`（触及带）；反转确认：`close_t > high_{t−1}`；量比 0.8–1.5（缩量回踩 = 噪声而非趋势反转）→ **模型确认区**。
- 失效事件 `F_t`（同 TR-01 定义，本条独立计算）：放量（≥1.5）跌破 `MA20 − 0.5×ATR5` = 趋势分量 c_t 下移的证伪事件 = **理论失效点**。
- 条件期望：`E[r_{t+1} | 回踩∧确认] = μ_c + θ·|x_t|·e^{−θ} − 成本`。

**③ 策略**

| 要素 | 规则 | 模型溯源 |
|------|------|---------|
| 方向 | 多空对称；空头距涨停 < 1×ATR5 禁开（逼仓保护，risk-framework Hard）；**[H7] OIΔ ±2% 条件默认禁用**，待用户明确解禁后按 t3 原设计恢复 | 状态条件 |
| 入场 | U 态 ∧ 触及 MA20±0.25×ATR5 带 ∧ 反转确认 K → T+1 开盘；跳空 > 0.75×ATR5 放弃（跳空越过入场带 = 噪声已释放、edge 消失） | 确认区 |
| 初始止损 | 回踩极值∓0.25×ATR5；**止损距离 > 1.5R → 放弃该笔** | edge = θ·\|x_t\| 有限（噪声 edge 定价） |
| 失效退出 | 收盘 < MA20−0.5×ATR5 且量比 ≥1.5 → 次日开盘离场 | F_t（c_t 下移） |
| 目标 T1 | 前期波段高/低点或 3d p68 上/下沿 [cap-6：锥=Yang-Zhang 波动投影，provenance=probability.json]，先到者，平 50% | x_t→0（edge 耗尽） |
| 目标 T2 | 2R–3R；余仓 1×ATR5 移动止损 | 趋势漂移 μ_c 部分 |
| 时间止损 | 8 个交易日未触及 T1 → 全平 | θ 衰减 |
| 仓位 | `|x_t|/ATR5 ∈ [0.5,1)`→0.5R；`≥1`→1R（edge 强度档） | θ·\|x_t\| 强度 |
| 加仓 | 突破 T1 且量比 ≥1.2 → +0.5 单位（止损上移 1×ATR5），最多 1 次 | 状态升级 |

**④ 数据契约**：引用 `04-data-contracts.json → TR-03`（available）。依赖：`data/daily`（MA/ATR/量比库内派生；**OIΔ 字段禁用，H7**）+ probability.json 3d 锥（cap-6，仅目标定价）。**落地门槛（prerequisites，cap-3）：GA-1、GA-2**（GA-2：3d p68 锥依赖 probability 派生管线）——未完成不得进入 in_validation。asOf：T 日收盘、T+1 开盘（F1 合规）。

### 3.3 TR-06 事件冲击确认（冲击分解：持久信息 vs 瞬时情绪）【交易系统】

**来源**：t3 §6。**证据级**：B（案例一致 + 外部事件研究，规则未回测）。

**① 核心理论（可证伪命题）**
- H0：事件日当日追入与"确认式/回踩式延迟入场"的样本外收益差 < 0.5R（等待确认无增益）。
- H1：事件日 D（`|r_D| ≥ max(2×ATR5, 3%)` ∧ 量比 ≥ 2 ∧ 存在可识别驱动）后，冲击分解为持久信息分量 `A·e^{−λk}` 与瞬时情绪分量 `S·e^{−γk}`（γ ≫ λ）；"确认式/回踩式"入场对持久分量的捕获优于当日追入，优势 ≥ 0.5R。
- 机制：信息处理需要时间（Hong & Stein 1999：反应不足 → 事件后漂移；过度反应 → 情绪回吐）；不同冲击持续性不同（Kilian 2009：供给冲击持续、需求冲击易反转）→ "等确认"是模型内在要求。

**② 市场模型**
- 事件判定：`D = 1{|r_D| ≥ max(2×ATR5, 3%)} × 1{量比_D ≥ 2} × 1{Q1 存在可识别驱动}`——Q1 驱动文本（FinCoT 分析层）仅作事件识别过滤器（H1 允许），不进入定价。
- 冲击分解：`r_{D+k} = A·e^{−λk} + S·e^{−γk} + ε`，γ ≫ λ。
- 持久分量确认（多）= **模型确认区**：`close_{D+1..D+2} > high_D` ∧ 量比持续 ≥ 1.2（资金进场代理；**[H7] 原 OIΔ ≥ +2% 条件默认禁用**，待解禁恢复 t3 原设计）；回踩变体：回撤 ≤ 事件区间 50% ∧ 连续 2 日收盘站稳事件区间中点上方（S 已释放、A 未衰减）。
- 失效 = **理论失效点**：收盘回到事件前 5 日区间内（A=0，事件影响消退）；**[H7] "多头 OIΔ 转负"失效条件默认禁用**。

**③ 策略**

| 要素 | 确认式 (a) | 回踩式 (b) |
|------|-----------|-----------|
| 入场 | D 后 T+1/T+2 收盘 > high_D ∧ 量比持续 ≥ 1.2 [H7 替代原 OIΔ≥+2% 条件] → 次日开盘 | 回撤 ≤ 50% 区间 ∧ 2 日站稳中点上方 → 第 3 日开盘 |

| 目标 T2 | 2×事件区间投影或 3R，先到者 | 同左 |

| 仓位 | 0.5–1R（`|r_D|/ATR5` 分档 = edge 强度） | 同左 |
| 加仓 | 浮盈 ≥1R 且量比维持 ≥ 1.2 [H7 替代] → +0.5 单位，最多 1 次 | 同左 |

### 3.4 FS-02 基差分位回归（现货–期货收敛）【基本面】

**来源**：t2 §FS-02。**证据级**：B（理论 A 级 + 数据可立即回测）。

**① 核心理论（可证伪命题）**
- F1（H0）：基差率 `br = (S−F)/S` 非平稳回归序列；处于极端分位（|z|≥1.5）后 20 日内基差向 180 日中枢回归概率 ≤ 0.5。
- F1（H1）：回归概率显著 > 0.5（Theory of Storage：基差 = 便利收益 − 持有成本，Kaldor 1939 / Working 1949；Fama & French 1987 基差对期货收益有预测力）。
- F2：期货深度贴水（z≤−1.5）时收敛以"期货向现货靠拢"为主 → 期货端做多收益为正；深度升水（z≥+1.5）→ 期货端做空；**收敛方向不对称性本身纳入证伪检验**。

**② 市场模型**
- `br_t = (S_t − F_t)/S_t`（akshare `dom_basis_rate` 主力口径）；`μ̂, b̂_hi, b̂_lo` = 180 日主力基差 平均/最高/最低（`futures_spot_price_previous` 直接提供）；`σ̂ = (b̂_hi − b̂_lo)/4`；`z_t = (br_t − μ̂)/σ̂`。
- 信号：`+1 if z_t ≤ −1.5`；`−1 if z_t ≥ +1.5`；`0 其他`。
- 目标价（模型导出）：`F_target = S_t × (1 − μ̂)`（基差回归 180 日中枢时对应的期货价 = edge 衰减点）。
- 确认区：T 日收盘 br 触发 + 现货质量门通过 + |z| 未处于加速走扩段（连续 3 日 |z| 递增 → 等待企稳）。
- 失效点：br 继续反向走扩 0.5σ̂（信号强化失败 = 理论失效点）；逼仓保护：距交割月 < 20 交易日不交易。

**③ 策略**

| 要素 | 规则 | 模型溯源 |
|------|------|---------|
| 方向 | z≤−1.5 → 多期货腿；z≥+1.5 → 空期货腿（现货不可交易，不做现货腿） | 收敛方向 |
| 入场 | 确认区触发 → T+1 开盘 | br 触发 + 质量门 + 无加速走扩 |
| 止损 | ① br 反向走扩 0.5σ̂；② 1.5×ATR5 反向。先到先平 | 理论失效点 + 波动失效 |
| 目标 | `F_target = S_t × (1 − μ̂)`，S_t 取触发日现货价；达到或 20 日时间退出 | edge 衰减点（基差归零隐含价） |
| 仓位 | 由 G2 波动率 overlay + risk-framework 1R 预算执行（t2 原条目无独立仓位公式） | 通用风险预算 |
| 持有 | ≤ 20 交易日 | 回归半衰期 |

禁止引用 FinCoT 文本价位/概率（thesis.odds/confirm、报告目标价，H1）；本条目标价仅由 `F_target` 模型方程导出（不引用概率锥）；FinCoT 方向冲突 → 观察。

**④ 数据契约**：引用 `04-data-contracts.json → FS-02`（available）。依赖：`futures_spot_price_daily`（2011+ 基差历史）+ `futures_spot_price_previous`（180 日分布锚）。**落地门槛（prerequisites，cap-3）：基差历史批量采集器（PIT 拉取，F7）、GA-6 现货粘性质量门（30 日零变动占比 >40% 的品种剔除出可交易集）、GA-1**——全部完成前不得进入 in_validation；期货腿 `data/daily`。

**⑤ 证伪测试**
- (a) z 触发后 20 日"基差向 μ̂ 收敛"命中率 < 55% → 证伪 F1；
- (b) 触发后 20 日期货端收益（扣 0.07% 成本）组合夏普 < 0.5 → 停用；
- (c) F2 不对称性检验：深贴水端与深升水端收益符号不对称性不显著 → 双侧规则改为对称（模型修订，不改变证伪门槛）。
- 已知反面证据必须写入策略库：2022 伦镍逼仓、2024 氧化铝逼仓（基差极端但继续走扩，止损硬执行）。

**参数表**：z 阈值 ±1.5、σ̂=(hi−lo)/4（来源：t2 §FS-02，180 日带直接可用，阈值待验证）、止损 0.5σ̂、20 日、质量门 40%、交割 20 日。

### 3.8 EC-01 能化成本传导误差修正（M4 ⊕ FS-08 合并条目）【宏观/成本】

**来源**：t1 §M4 ⊕ t2 §FS-08（D2 合并裁定）。**证据级**：C（ECM 范式成熟，国内油化工品种对未验证；t1 M4 原评中-高，合并后如实降为 C）。

**① 核心理论（可证伪命题）**
- F1：原油是油化工品种的成本锚，产品价与 SC 价存在协整；短期偏离通过产品端以误差修正机制回归（ECM 修正系数 γ 显著 < 0）。
- F2：产品端偏离成本锚的 z-score |z|≥2 后，20 日内产品价格向成本锚回归；**回归由产品端承担**（SC 端受外盘主导，不构成可交易的回归腿——t4 确认 SC 无库存/基差数据，产品腿单边结构是正确取舍）。

**② 市场模型**
- 协整：`P_prod,t = α̂ + β̂·P_SC,t + e_t`（滚动 250d，冻结参数）。
- ECM：`ΔP_prod,t = γ·e_{t−1} + Σ β_j·ΔP_SC,t−j + ε_t`；**γ < 0 且 p < 0.05 为启用前提**（模型级可证伪门）。
- 模型资格测试（合并自 M4 防伪绑定）：`β̂ ≥ 0.2 且 R² ≥ 0.3`，否则该品种剔除出池（传导不显著）。
- 信号：`z_t = (e_t − μ̂_e)/σ̂_e`；`−1 if z_t ≥ +2`（产品高估 → 空产品）；`+1 if z_t ≤ −2`（产品低估 → 多产品）。
- 目标价（模型导出）：`P_target = α̂ + β̂·P_SC,t + μ̂_e`（误差归零的模型导出产品目标价 = edge 衰减点）。
- 确认区：T 日收盘 |z|≥2 + γ 显著性门通过 + 产品 `close ≥ MA20`（多侧）。
- 失效点：e 反向扩 0.5σ̂_e（回归失败 = 理论失效点）或产品 1.5×ATR5。

**③ 策略**

| 要素 | 规则 | 模型溯源 |
|------|------|---------|
| 方向 | 只做产品腿（不裸做 SC 腿：无库存/基差数据 + 原油波动受外盘主导，与模型回归假设不符） | F2 回归由产品端承担 |
| 入场 | 确认区触发 → T+1 开盘 | z 阈值 + γ 门 + MA20 |
| 止损 | ① e 反向扩 0.5σ̂_e；② 产品 1.5×ATR5。先到先平 | 理论失效点 + 波动失效 |
| 目标 | `P_target = α̂ + β̂·P_SC,t + μ̂_e`；20 日时间退出 | edge 衰减点 |
| 仓位 | 通用风险预算 × 0.75（回归策略折价，σ 估计误差折价；来源 M4，待标定） | edge 强度折价 |
| 隔夜保护 | SC 夜盘与外盘跳空 → 产品次日开盘跳空 > 1×ATR5 的交易日不新开仓；已持仓位跳空反向按止损硬执行 | 执行纪律（t2 §FS-08） |

**④ 数据契约**：引用 `04-data-contracts.json → FS-08`（available；M4 的池资格过滤并入本条，契约已在审计中说明）。依赖：`data/daily/{SC0,TA0,EG0,PP0,L0,EB0,BU0,FU0,PG0,PX0}.json`（SC0 已有 500 bars）。**落地门槛（prerequisites，cap-3）：GA-1（化工品回填，标定需 ≥750 日）**——未完成不得进入 in_validation。asOf：T 日收盘；滚动 OLS/ECM 只用 T 日及以前数据（F8 合规）。**MA 不入集**（煤化工成本锚是煤而非油，保持模型内一致性）。

**⑤ 证伪测试**
- (a) 残差 ADF p > 0.05（无协整）或 γ ≥ 0（无误差修正）→ 该品种对证伪；
- (b) 策略扣成本夏普 < 0.5 → 停用；
- (c) 隔夜跳空亏损占策略总亏损 > 30% → 增加隔夜过滤（半仓/仅日内评估），修订后仍 > 30% → 停用；
- 结构性失效：2020 负油价、2022 俄乌供给冲击期样本单列报告，不参与参数估计；该期必须与 FS-09 事件日历联动暂停。
- 已知反面证据写入策略库：2022 俄乌段 SC 暴涨而化工品跟涨滞后、幅度不足（ECM 长时偏离，z 极端持续数周）。

**参数表**：滚动 250d、z 阈值 ±2、γ 显著性 p<0.05、止损 0.5σ̂_e/1.5×ATR5、20 日、池资格 β̂≥0.2 且 R²≥0.3、标定 ≥750 日、仓位折价 0.75（来源 t1 M4/t2 FS-08，待标定冻结）。

## 4. 治理层组件与组合纪律（非定价）

> 治理层组件只做过滤/缩放/否决，**不产生方向、不产生止损/目标/仓位数值**（H1/H3）。它们有各自的证伪测试与停用规则：失效即退化回"无过滤原样执行"，不影响任何核心策略自身的定价链。

### 4.1 G1 风险偏好 regime 过滤器（来源 t1 §M5）

- **状态变量**：`R_t = Σ_{k=1..5} 1(条件_k)`：① `DXY.change5d < 0`；② `US10Y.change5d < +0.20pp`；③ `USDCNH.change5d < 0`；④ `DR007 < 2.0% 且 change5d < +0.5pp`；⑤ `SC0.change5d > −1%`。
- **作用**：R ≥ 3 → 顺周期多头候选满仓执行、空头候选半仓；R ≤ 1 → 禁止多头新仓、空头正常；1.5 < R < 3 → 所有信号半仓。极端预警：`US10Y.change5d ≥ +0.25pp` 或 `DXY.change5d ≥ +1%` 单锚触发 → 全部 regime 依赖仓位提前降半。
- **数据契约**：引用 `04-data-contracts.json → M5`（available；GA-4/GA-5 前置；stale 锚点计 0.75、missing 计 0）。
- **证伪测试**：walk-forward 6 个月窗口：R≥3 期顺周期多头命中率 vs 同池无过滤基线必须提升 ≥ 5pp（R≤1 期同理）；连续 2 窗口无提升 → 停用过滤；锚点相关性 24 月滚动符号翻转 → 剔除该锚重标定（不得沿用旧阈值）。

### 4.2 G2 波动率目标 overlay（来源 t1 §M6，与 risk-framework §2 同源）

- **状态变量**：`σ_i,t = hv.annual`（20 日 Yang-Zhang 年化）；`scale_i = clamp(σ_target/max(σ_i,t, 0.05), 0.2, 1.0)`，σ_target 默认 0.15（t1）；risk-framework 同口径：单仓波动贡献目标 10%（5%–15%）、组合波动目标 ≤20% Hard。
