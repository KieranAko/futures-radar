## 三、关键发现

### 1. **边际收益在 ER≥0.20 后开始递减**

**边际收益比 (Marginal Benefit Ratio)** = 过滤掉的Miss / 过滤掉的Hit

- **ER≥0.20**: 边际收益比 **1.05:1** — 唯一超过1:1的阈值
  - 过滤掉43个样本：21 hit + 22 miss
  - 每删除1个hit，同时删除1.05个miss（正边际收益）

- **ER≥0.25**: 边际收益比降至 **0.96:1**
  - 过滤掉45个样本：23 hit + 22 miss
  - 每删除1个hit，只删除0.96个miss（负边际收益）

- **ER≥0.30及以上**: 边际收益比持续恶化（0.80:1 → 0.65:1）

### 2. **被过滤样本并非纯噪音**

所有阈值的被过滤样本命中率均 **≥48.8%**，显著高于随机水平：

- ER≥0.10: 过滤样本命中率 **58.3%**（接近基线63.9%）
- ER≥0.25: 过滤样本命中率 **51.1%**
- ER≥0.50: 过滤样本命中率 **60.8%**（反而更高）

**结论**: 当前被过滤掉的样本中，**超过一半仍然是有效机会**。

### 3. **最高命中率 ≠ 最优阈值**

- **最高命中率**: ER≥0.35 达到 **75.7%**
- **但样本量降至37**，品种集中度 **32.4%**
- 边际收益比仅 **0.79:1**（负收益）

### 4. **时间稳定性问题**

多个阈值出现 **>10pp 的前后半段命中率差异**：

- ER≥0.10: **16.4pp gap** (57.9% → 74.3%)
- ER≥0.30: **13.3pp gap** (66.7% → 80.0%)
- ER≥0.20: **11.8pp gap** (69.0% → 80.8%)

这表明 **样本内过拟合风险**，后半段表现显著优于前半段。

### 5. **品种集中度随阈值升高恶化**

- 基线: Top3品种占 **25.8%**
- ER≥0.25: Top3品种占 **30.2%**
- ER≥0.40: Top3品种占 **39.3%**
- ER≥0.50: Top3品种占 **47.4%**（接近一半）

高阈值导致 **品种多样性严重下降**。

## 四、边际递减点判定

根据边际收益比和被过滤样本命中率，边际递减点为：

### **ER≥0.20 是最后的正边际收益点**

- 边际收益比 **1.05:1** > 1（唯一）
- 命中率 **74.5%**（vs 基线63.9%，提升10.6pp）
- 被过滤样本命中率 **48.8%**（首次低于50%）
- 覆盖率 **3.2%**（55个样本）
- 稳定性gap **11.8pp**（需警惕过拟合）

### **ER≥0.25 已进入负边际收益区**

- 边际收益比 **0.96:1** < 1
- 相比0.20只提升2个样本，但删除了2个额外的hit
- 被过滤样本命中率回升至 **51.1%**（说明删错了）

## 五、语义一致性问题

### 发现的不一致
生产代码 `calculateER20()` vs 实验代码 `calculateER()`：

```javascript
// 生产版本 (lib/features.js:75-77)
if (sumChanges === 0) {
  return 0;  // 全平价格返回0
}

// 实验版本 (experiments/lib/opportunity-features.js:30-31)
if (sumAbsChanges === 0) return null;  // 全平价格返回null
```

**影响**: 当合约全天无波动时（收盘价连续不变）：
- 生产版本: ER=0，会被ER≥0.20过滤掉
- 实验版本: ER=null，直接跳过（continue）

**建议**: 统一为 `return 0`，与生产代码保持一致。
