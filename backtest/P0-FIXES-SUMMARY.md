### ✅ P0-1: 方向计算验证

**状态**：✅ 已验证通过
**问题**：EMA20-relaxed 模型的 directionSign 计算需要审查，确认做空收益计算正确性。

**验证结果**：
- 模型文件 `models/momentum-ema20-relaxed.cjs` 仅生成信号（symbol, direction, confidence）
- 实际收益计算在 `strict-backtest.cjs:527-528`：
  ```javascript
  const directionSign = direction === 'bullish' ? 1 : -1;
  const grossReturn = directionSign * (exit.exitPrice - entry.entryPrice) / entry.entryPrice;
  ```
- **做空收益计算正确**：
  - 做多（bullish）：directionSign = +1，价格上涨盈利
  - 做空（bearish）：directionSign = -1，价格下跌（负收益）× -1 = 正盈利
  
**示例验证**：
- 做空，入场100，退出90：(90-100)/100 = -10%，乘以-1 = +10% ✓
- 做空，入场100，退出110：(110-100)/100 = +10%，乘以-1 = -10% ✓

**结论**：方向计算实现正确，无需修复。
