## 2. 根因（按层次）

### R1 构造顺序错误：目标 → 源 → 证据
允许"从信号质量假设出发"的授权被误用成"从信号反推一切"。源的选择应该独立于品种方向：**删掉 RB 价格与黑色板块快照后，"需求走弱"这个源仍应独立成立并独立可测**。本案删除 RB 信号后，只剩一条为它量身定做的检索。

### R2 concept 承载结论
`concept` 本应是"被测量的量 + 窗口 + 基准"（中性口径），方向放在 `expectation`。写成"全国建筑钢材成交量同比走弱"后：
- 检索 brief 必然把结论带进搜索引擎；
- 注册校验无法区分"口径"与"结论"；
- 下游渲染、审计都把结论当事实展示。

### R3 口径没有冻结
"全国 vs 重点城市""建筑钢材 vs 钢材""日环比 vs 同比"三个维度全部漂移，而旧 resolve 契约只校验 `value/asOf/sourceUrl/sourceTier`。单条 9.89 万吨、-23.17% 的兰格口径数据，不能支撑"全国建筑钢材成交量同比走弱"这个概念。

### R4 flow 被当作 event 处理
成交量是典型流动型指标（日度噪声序列），必须多源交叉；本案单源 B 级媒体转载直接确认。`kind` 缺失时旧路径按单源放行。

### R5 存量链不受新契约约束
契约已经收紧，但已入池的旧链永不重验。契约升级只挡住了"新错误"，挡不住"还活着的旧错误"。

### R6 provisional 不撤销节点判决
provisional 只阻止链级 proven 与席位，不清除/不冻结节点级 `confirmed`，也没有阻止它继续占用同源唯一席位。

## 3. 本轮已落地修复（P0/P1）

### P0 处置
- `CH-BLACK-20260921-02` 已 **void**，closeReason 记录"首节点证据无效：concept 预置方向结论，按螺纹信号反搜单源硬凑数据……"；黑色源席位释放，事件留档可审计。

### P1 构造契约与解析防线（`stories/lib/story-chain.cjs`）
1. **concept 中性化**：T2 concept 出现方向结论词（走弱/下降/上行/回落/跑输/收紧…）注册直接拒收；方向只能写 `expectation`。
2. **flow 口径冻结**：`kind=flow` 必须显式 `metric`（被测量的具体指标名）+ `basis`（level|dod|wow|mom|yoy）+ `minSources` 2..5；concept 必须指向可计量对象（成交量/库存/开工/价格/利率/产量等），禁止结论性状态描述。
3. **检索词中性化**：`generateResolveBrief` 不再把 concept 当检索词；queries 只由中性 `searchHints` + `metric` + basis 标签拼出。searchHints 为空或含方向结论词 → 注册拒收。
4. **解析口径一致性**：flow observation 必须携带 `metric` 与 `basis`，与 dataPlan 不一致即拒收——"日环比冒充同比"（dod≠yoy）、"重点城市钢材冒充全国建筑钢材"（metric 不一致）两条路径都堵死；多源独立域名与方向一致校验保留。
5. **存量合规审计**：新增 `auditChainCompliance` / `auditActiveChains` 与 CLI `audit [--chainId <id>]`，按当前契约复查存量活跃链。本次事故链被 audit 精准标出两条 FAIL（concept 方向词、kind 缺失）。
6. **提示词/蓝图/SKILL.md**：加入"源优先，目标其次"步骤与反证自检——*删除品种价格与板块快照后源依然成立，才允许作链首*；T2 契约同步 metric/basis/中性检索描述。

测试：`test/story-chain-v21.test.js` 新增 7 个用例（反证预防、口径错配拒收、brief 中性查询、存量审计）。全量 **891/891 通过**。

**尚未做的优化（P2 候选，需要决策）**

1. **T2 源目录（源侧白名单）**：像 T0 指标目录一样维护 `story-chain-t2-sources.json`，只有预先登记（含机构、序列、口径、basis、kind、minSources）的源才能作 T2 节点。链构造只能引用目录 ID，不能自由发明 concept。这是从结构上消灭"反搜凑源"的根本手段，代价是源目录需要有人维护。

4. **新链注册前置 audit**：`register --batch` 前自动跑存量 audit，存量 FAIL 的活跃链必须 void/supersede 后才能注册同源新链（现在靠人工跑 audit）。
5. **信号池反哺**：链证伪/作废时联动信号池出池（`link-signal-pool.cjs` 仍暂未启用），本案例证明这条联动值得恢复。

## 5. 给未来构造工作的三句纪律

- **源必须能独立生存**：删掉品种价格和板块快照，源还在、方向还在、还能监测，才允许作链首。
- **方向只属于 expectation**：concept 和检索词里出现"走弱/上涨/回落"就是反搜的报警信号。
- **流量数据不单源**：成交量、库存、开工这类噪声序列，两个独立机构同口径同方向才配做证据。
