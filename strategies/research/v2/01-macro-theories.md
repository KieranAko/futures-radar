### 0.3 P0 / P1 划分标准

- **P0（可落地）**：①核心理论可证伪且②模型公式完备、③所需数据全部 available（或仅用 available 字段即可运行的版本）、④证伪测试可直接用 macro-history + raw.json 回测执行。
- **P1（仅参考）**：理论扎实但 ①数据 needs-extension（未接入）或 ②频率为月度/事件型、只适合做中期 regime 背景或需先扩展采集。

### 0.4 与 FinCoT 的边界（写入本文件，供 t5 架构师强制校验）

1. FinCoT 的 `thesis.odds/confirm/invalidation` 是**分析叙事**，可用于"候选方向从哪里来"，但策略的入场确认、止损、目标、仓位计算**只读策略自身模型变量**（MA20/60、ATR5、HV、锚点 change5d、价差 z 分数等原始数据派生量）。
2. 策略可把 FinCoT 方向候选作为**触发器**（例如"FinCoT 给出多头候选 + M1 流动性模型确认 → 开仓"），但触发器本身不产生任何数值定价。

## 1. P0 候选（数据已接入，可落地）

### M1 流动性冲击策略 —— DR007 突变 → 国内需求型板块（黑色/玻璃纯碱）

**① 核心理论（可证伪命题）**
信用渠道/流动性溢价理论：短期资金利率是央行政策姿态的最高频观测，DR007 相对政策利率（7 天逆回购）的偏离冲击会通过融资成本与信用条件传导至地产-基建链需求预期，进而影响国内定价为主的工业品（黑色、玻璃纯碱）。
- H0：DR007 的 5 日突变与黑色板块未来 1–2 周收益无关。
- H1：资金利率急升（收紧冲击，Δ5d DR007 ≥ +0.5pp）后，国内需求型品种未来 10 日收益系统性为负；宽松冲击（≤ −0.5pp）后为正。

**② 市场模型（状态变量 + 公式）**
- 状态变量：`s_t = Δ5d DR007_t`（百分点）；扩展状态（needs-extension 版本）：`g_t = DR007_t − r*_t`，r* 为 7 天逆回购政策利率——P0 只使用 `s_t`（已接入，日频）。
- 传导机制：`s_t > 0`（收紧）→ 票据/信用利差上行 → 地产基建资金成本上升 → 黑色需求预期下修 → RB0/HC0/J0 承压；传导时滞 1–10 个交易日，幅度与 |s_t| 成比例。
- 条件模型（线性简化，参数滚动标定）：
  `E[r_{i,t+1:t+10} | s_t] = α_i + β_i · s_t`，预期 β_i < 0（i ∈ 黑色 + SA/FG 等国内需求型能化）。
- 方向门禁（模型自带的确认，不是 FinCoT 叙事）：价格 `close_t ≤ MA20` 且 `close_t ≤ MA60` 时才执行空头；多头对称。信号与价格确认同向才入场。

**③ 策略（定价全部由②导出）**
- 方向：`s_t ≥ +0.5pp` 且价格破 MA20/MA60 → 做空国内需求型品种（RB0/HC0/J0/SA0/FG0 候选池）；`s_t ≤ −0.5pp` 且价格站上 MA20/MA60 → 做多。|s_t| < 0.5pp 为中性，不开新仓。
- 入场：信号日收盘确认（T+1 开盘执行，避免用当日未完成 bar）。
- 止损：`stop = entry ± 1.5 × ATR5`（ATR5 来自 probability.json，模型自身波动量）。
- 目标：`target = entry ∓ 2.0 × ATR5`（第一目标）；或持有至 `|s_t| < 0.3pp`（冲击消化）先到先平。风险收益比固定 1:1.33，无任何 FinCoT odds 参与。
- 仓位：`scale = clamp(σ_target / max(hv, 0.05), 0.2, 1.0) × min(1, |s_t| / 1.0)`（hv 来自 probability.json 年化 HV；σ_target 默认 0.15，见 M6）。

**④ 数据依赖**
- DR007 日频：akshare `repo_rate_hist`（FDR007 定盘）→ 已接入宏观快照 + macro-history recordings。**available**。
- 黑色/玻璃纯碱日线 OHLCV：raw.json/daily。**available**。
- ATR5/HV：probability.json。**available**。
- 扩展（可选）：7 天逆回购政策利率 r* 序列（akshare 公告口径）——needs-extension，不影响 P0 运行。

**⑤ 证伪测试（样本外门禁）**
- 用 macro-history DR007 + daily bars，walk-forward：2019-01–2026-08 滚动 12 个月窗口，每窗口内统计"冲击后 10 日方向命中率"。
- 通过门槛：命中率 ≥ 55% 且单尾检验 p < 0.10（至少 8 个滚动窗口 ≥ 55%，允许个别窗口失效）。
- 停用规则：连续 2 个滚动窗口命中率 < 50% → 冻结该品种方向映射；全池 < 50% → 策略整体停用并回炉 β 标定。
- 结构性风险：国内利率与地产链脱钩（2023 后地产周期走平）可能使 β_i 衰减——证伪测试必须分 2023 前后两段报告。

### M2 美元/人民币汇率传导策略 —— DXY/USDCNH → 有色与进口成本品种

**① 核心理论（可证伪命题）**
计价货币与进口成本理论：以美元计价的全球金属随 DXY 反向变动（Gorton-Rouwenhorst 2006 商品风险溢价框架的计价效应）；人民币贬值推升进口依存度高的品种（油粕、铜）内盘成本与相对价格。
- H0：DXY 5 日变化与有色金属未来 5–10 日收益无关；USDCNH 变化与进口油粕内盘收益无关。
- H1：β_dxy < 0（美元强 → 有色承压）；β_cnh > 0（人民币贬 → 进口成本型品种内盘相对偏强/空头回避）。

**② 市场模型（状态变量 + 公式）**
- 状态变量：`d_t = Δ5d DXY_t`（%）、`f_t = Δ5d USDCNH_t`（%）。均已接入宏观快照 + macro-history。
- 传导机制：DXY↑ → 外盘美元定价下移 → 内盘跟随但被汇率缓冲；USDCNH↑（人民币贬）→ 进口成本 = 外盘价 × 汇率 × (1+升贴水/关税) 上升 → 内盘相对外盘走强（沪伦比类价差扩张）。
- 线性模型：`r_{i,t+1:t+5} = α_i + β^{dxy}_i · d_t + β^{cnh}_i · f_t + ε`
  - 有色（CU/AL/ZN/PB/NI/SN）：预期 β_dxy < 0、β_cnh ≈ 0~正。
  - 进口油粕（M/Y/P/RM/OI）：预期 β_dxy < 0（外盘跟随）、β_cnh > 0（成本对冲）。
- 共振条件（模型自带）：仅当 `d_t` 与 `f_t` 同向（美元强 + 人民币贬，或双弱）时信号为"强"；单锚点信号为"弱"，仓位减半。

**③ 策略**
- 方向：强信号（d_t ≥ +1.0% 且 f_t ≥ +0.3%）+ 有色价格破 MA20 → 做空有色；强信号（d_t ≤ −1.0% 且 f_t ≤ −0.3%）+ 价格站上 MA20 → 做多有色。
- 进口成本腿：f_t ≥ +0.3%（人民币贬值）→ 禁止油粕新开空头（成本支撑），油粕多头候选加 0.5 权重；f_t ≤ −0.3% → 反之。该腿是**过滤器**不是独立信号。
- 入场：T+1 开盘执行；止损 `1.5 × ATR5`；目标 `2.0 × ATR5` 或锚点信号反向（d_t 回 0 带 ±0.3%）先到先平。
- 仓位：`scale × 信号强度`（强=1.0，弱=0.5）；scale 同 M1 定义。

**④ 数据依赖**
- DXY：sina DINIW 日线 → **available**（宏观快照已接，历史序列见 macro-history）。
- USDCNH：sina 日线 → **available**。
- 有色/油粕日线、ATR5/HV → **available**。
- 扩展（P1 研究项）：沪伦比/内外价差需 LME 铜铝外盘历史——**needs-extension 未验证**（见第 3 节剔除清单备注），P0 不使用。

**⑤ 证伪测试**
- walk-forward 12 个月滚动窗口：β_dxy（有色池）符号一致性 ≥ 70% 窗口数，且显著窗口命中率 ≥ 55%；否则冻结该品种。
- 汇率与商品相关性漂移监测：连续 2 个窗口 β 符号翻转 → 停用该品种映射。
- 分年报告（2019–2026）：美元-商品负相关在 2020–2021（全球宽松+商品牛市）与 2022（强美元+商品回落）两段必须成立，任一段不成立即降级。

### M3 美债实际利率 → 贵金属策略 —— US10Y 突变驱动 AU/AG

**① 核心理论（可证伪命题）**
持有成本/实际利率机会成本理论：贵金属是无息资产，实际利率是持有黄金的机会成本（黄金定价负相关于实际利率；Erb-Harvey 2006 框架 + 名义利率为可得代理）。
- H0：US10Y 5 日变化与 AU0/AG0 未来 10 日收益无关。
- H1：β < 0——US10Y 快速上行（Δ5d ≥ +0.20pp）后贵金属未来 10 日收益系统性为负；快速下行后为正。

**② 市场模型（状态变量 + 公式）**
- 状态变量：`r_t = Δ5d US10Y_t`（百分点，已接入宏观快照 + macro-history）。
- 传导机制：名义利率↑ 且短期通胀预期粘性 → 实际利率↑ → 持有黄金机会成本↑ → 金价承压；内盘额外受 USDCNH 换算影响（`P_内盘 ≈ P_外盘 × USDCNH × (1+溢价)`，溢价序列无公开高频数据，P0 不建模，仅用 US10Y 单锚点）。
- 线性模型：`r_{i,t+1:t+10} = α_i + β_i · r_t`，预期 β_i < 0（i = AU0, AG0）。
- 价格确认：`close_t ≤ MA20`（空）或 `≥ MA20`（多）与信号同向才入场——防止利率信号与趋势背离时误伤。

**③ 策略**
- 方向：`r_t ≥ +0.20pp` 且 AU0/AG0 破 MA20 → 空；`r_t ≤ −0.20pp` 且站上 MA20 → 多。
- 入场：T+1 开盘；止损 `1.5 × ATR5`；目标 `2.0 × ATR5` 或持有至 `|r_t| < 0.10pp` 先到先平。
- 仓位：`scale`（hv 缩放）+ 贵金属波动上限：AU/AG 的 hv 高时 scale 自动压缩（M6 机制），单品种名义上限由风控框架约束。
- 本策略只做方向性仓位，不做"溢价回归"（溢价数据不可得 → 剔除，见第 3 节）。

**④ 数据依赖**
- US10Y：akshare `bond_zh_us_rate` → **available**（已接入宏观快照，asOf 常滞后 1 日为 stale，规则必须容忍：stale 时按昨值参与但标注降权 0.75）。
- AU0/AG0 日线、ATR5/HV → **available**。
- 扩展（P1）：实际利率 = US10Y − 通胀预期代理（国内可用 PPI 环比年化做粗代理，`macro_china_ppi` needs-extension）；中美利差（`bond_zh_us_rate` 同表有中国 10 年列，needs-extension）。

**⑤ 证伪测试**
- walk-forward 12 个月窗口：β 符号一致性 ≥ 70% 窗口；命中率 ≥ 55%。
- 关键样本外：2024-03–2025（金价与美债利率同步上行、央行购金主导期）模型必须被标记失效——若该段 β 翻正，规则改为"该段禁用 M3，回归 M9 合成评分"。
- 停用：连续 2 个滚动窗口命中 < 50% → 冻结。

### M4 原油成本传导与能化价差回归 —— SC0 锚 → 能化板块

**① 核心理论（可证伪命题）**
成本推动与价差均值回复理论：原油是能化产业链成本锚，产品价格围绕"原油成本 + 加工利润（正常利润带）"波动；价差偏离正常带后向均衡回复（利润挤压→供给调节→价差修复）。
- H0：能化产品价对原油成本价差的偏离无均值回复。
- H1：价差 z 服从 OU 过程，偏离 2σ 后未来 10 日向均值显著回复（半衰期 5–20 交易日）。

**② 市场模型（状态变量 + 公式）**
- 状态变量：价差 `z_{i,t} = log P_{i,t} − (α̂_i + β̂_i · log SC0_t)`，α̂、β̂ 用滚动 250 日窗口 OLS 标定（只用 T 日及以前数据，无未来函数）。
- 传导机制：SC0↑ → 成本推升产品价（β>0）；短期超调/超跌形成 z 偏离 → 利润驱动开工调整 → z 回复。
- 均值回复模型：`dz = −κ·z·dt + σ_z·dW`，κ>0。目标位 = 均值（z=0 的隐含产品价）；半衰期 `t_{1/2} = ln2/κ`。
- 适用品种池：SC0 与成本链直接的品种（FU/LU/BU/SC 系、TA/PX/EG/PP/L/V/EB 等）；β̂_i < 0.2 或 R² < 0.3 的品种剔除出池（传导不显著，防伪绑定）。

**③ 策略**
- 入场：`|z| ≥ 2σ_z` 且当日价格对 MA20 方向与回归方向一致（防抓刀）→ 开回归仓：z > 2σ_z → 做空产品（价差回落）；z < −2σ_z → 做多产品。T+1 开盘执行。
- 止损：`|z| ≥ 3σ_z`（模型证伪，立即离场）或价格反向 `1.5 × ATR5`，先触发者生效。
- 目标：`z → 0`（价差回到均值），即产品目标价 `P* = exp(α̂ + β̂·log SC0_t)`；持有上限 20 个交易日（超时未回复则平仓并记录模型失效事件）。
- 仓位：`scale × 0.75`（回归策略折扣，σ_z 估计误差折价）。

**④ 数据依赖**
- SC0 与能化品种日线：raw.json/daily → **available**。
- 参数 α̂、β̂、σ_z、κ：由上述日线滚动标定，**无额外数据依赖** → **available**。
- 注意：本模型用的是"价格-价格"链式关系（数据内自洽），不引入利润/库存（那是基本面分析师 t2 的范围，跨条目不可混用）。

**⑤ 证伪测试**
- walk-forward：滚动 250 日标定 → 未来 10 日样本外检验，z 回复方向命中率 ≥ 55%，且回复幅度与 κ 估计一致（偏差 < 50%）。
- 半衰期稳定性：κ̂ 在滚动窗口间变化 < 2 倍，否则模型不稳定 → 降级。
- 结构性失效：原油定价机制切换（如 2020 负油价、2022 俄乌供给冲击期）→ 该期样本单列报告，不参与参数估计。

### M5 Risk-On/Risk-Off 合成评分 —— 五锚点风险偏好 regime 过滤器

**① 核心理论（可证伪命题）**
风险偏好 regime 持续性 + 下行贝塔理论（Ang-Chen-Xing 2006：下行贝塔解释力强于传统贝塔；regime 状态平均持续数月）。
- H0：多锚点合成评分与顺周期品种未来收益无关。
- H1：risk-on 评分 ≥3 期间顺周期多头候选未来 10 日正收益频率 > 60%；risk-off 评分 ≥3 期间空头候选负收益频率 > 60%；两者显著高于中性期基线。

**② 市场模型（状态变量 + 公式）**
- 状态变量：`R_t = Σ_{k=1..5} 1(条件_k)`，条件为（全部日频已接入）：
  1. `DXY.change5d < 0`（美元弱）；
  2. `US10Y.change5d < +0.20pp`（无紧缩冲击）；
  3. `USDCNH.change5d < 0`（人民币稳/强）；
  4. `DR007 < 2.0% 且 change5d < +0.5pp`（流动性宽松）；
  5. `SC0.change5d > −1%`（油价未崩塌）。
- R ∈ {0..5}；条件分布 `P(r_{i,t+1:t+10} > 0 | R_t ≥ 3)` 与 `P(· | R_t ≤ 1)` 由历史频率估计。
- stale 锚点（US10Y/USDCNH 滞后 1 日）按"昨日值参与但该锚点计 0.75"处理，评分可为小数；任一锚点 missing 时该项计 0 并标注。

**③ 策略（过滤器，不独立开仓）**
- R ≥ 3：允许顺周期多头候选（有色/黑色/能化/农产品中的多头信号）满仓执行；空头候选降级半仓。
- R ≤ 1：禁止多头新仓；空头候选正常执行。
- 1.5 < R < 3：所有信号半仓。
- 本条目不产生任何自身的入场/止损/目标——被过滤的底层策略（趋势/突破类，见 t3 交易员调研）用自己的模型定价。这是**风险偏好 regime 过滤器**，防止跨条目定价混用。
- 极端预警：`US10Y.change5d ≥ +0.25pp` 或 `DXY.change5d ≥ +1%` 单锚点触发 → 全部 regime 依赖仓位提前降半（与 M7 事件条目联动时取更保守者）。

**④ 数据依赖**
- 5 锚点：宏观快照 + macro-history → **available**。
- 被过滤标的：raw.json 全品种 → **available**。

**⑤ 证伪测试**
- walk-forward 6 个月窗口：R≥3 期顺周期多头命中率 vs 同池基线（无过滤），必须提升 ≥ 5 个百分点；R≤1 期同理。
- 连续 2 个窗口无提升 → 停用过滤（退化回底层策略原样执行）。
- 锚点相关性漂移：任一锚点与商品收益的相关符号在滚动 24 月窗口内翻转 → 该锚点从评分中剔除并重新标定阈值（剔除后评分门槛相应调整，不得沿用旧阈值）。

### M6 波动率目标 overlay —— 组合风险恒定缩放

**① 核心理论（可证伪命题）**
波动率管理理论（Moreira-Muir 2017）：按已实现方差的倒数缩放敞口可改善风险调整后收益。
- H0：固定仓位与波动率缩放仓位夏普无差异。
- H1：波动率缩放组合夏普显著更高、最大回撤显著更小。

**② 市场模型（状态变量 + 公式）**
- 状态变量：`σ_i,t = marketFacts.hv.annual`（20 日 Yang-Zhang 年化，probability.json 已接入）。
- 仓位公式：`scale_i = clamp(σ_target / max(σ_i,t, 0.05), 0.2, 1.0)`，σ_target 默认 0.15（年化 15%）。
- 模型稳定性门禁（divergence 指标）：`priceRanges[0].divergence.pct < 10%` → 用 scale；`10–20%` → scale×0.75；`>20%` 或 `hv.degraded` → scale×0.5 且止损改 ATR5 口径。

**③ 策略（overlay，无方向）**
- 所有 P0 方向策略的仓位统一乘 `scale_i`；`volPercentile ≥ 95` 时强制 `scale ≤ 0.5`。
- 无独立入场/退出/止损——overlay 不产生定价，只缩放敞口。

**④ 数据依赖**：probability.json（hv/volPercentile/divergence）→ **available**。

**⑤ 证伪测试**
- 用 daily bars 回测：同一底层信号在"固定仓位 vs scale 缩放"两臂下对比夏普/回撤（仓库已有 signal-backtest 设施）。
- 停用：若缩放臂连续 24 个月夏普不优于固定臂 → 退回固定仓位（但保留 volPercentile≥95 的硬减仓门禁）。

### M7 美债利率事件冲击 —— US10Y 单日突变 → 工业品 risk-off 脉冲

**① 核心理论（可证伪命题）**
紧缩冲击的贴现率/风险偏好瞬时传导（事件研究视角）：美债收益率单日大幅上行是紧缩冲击事件，对全球风险资产产生即时负向脉冲。
- H0：US10Y 单日 ≥10bp 上行后，国内工业品未来 5 日收益与基线无差异。
- H1：事件后未来 5 日工业品收益显著低于基线（负向脉冲），脉冲在 5 日内衰减。

**② 市场模型（状态变量 + 公式）**
- 事件定义：`Δ1d US10Y_t ≥ +0.10pp`（上行冲击）或 `≤ −0.10pp`（下行冲击）。US10Y 日频已接入。
- 条件分布：`P(r_{i,t+1:t+5} < 0 | 上行事件)` vs 基线 `P(r_{i,t+1:t+5} < 0)`；下行事件对称。
- 冲击幅度条件：`r 脉冲幅度 ∝ |Δ1d|`，|Δ1d| ≥ 0.25pp 的极端事件单独成组报告（样本少，只观察不交易）。

**③ 策略**
- 上行冲击事件（T 日收盘确认）→ T+1 开盘做空工业品池（RB0/CU0/TA0 等流动性前 10 品种中当日收破 MA20 者，最多 3 个）；持有 5 个交易日或触发止损/目标先平。
- 止损 `1.0 × ATR5`（事件策略止损更紧）；目标 `2.0 × ATR5`。
- 仓位：`scale × 0.5`（事件型半仓起步）。
- 事件频次门禁：滚动 24 个月事件数 < 30 → 本策略自动停用（样本不足，禁开新仓）——这是模型自带的样本充分性条件。

**④ 数据依赖**：US10Y 日频（akshare `bond_zh_us_rate`）→ **available**；工业品日线/ATR5/HV → **available**。美联储议息日历（公开信息，未结构化接入）为 P1 扩展项，P0 不依赖。

**⑤ 证伪测试**
- 事件研究：滚动窗口内事件组收益 vs 同池随机 5 日切片基线，t 检验 p < 0.10 且事件组方向命中 ≥ 55%。
- 分年失效检查：2023–2025（美债利率对国内工业品传导减弱期）若事件组效应消失 → 停用或降级为 M5 的评分输入。

## 2. P1 候选（理论扎实，数据 needs-extension 或低频/事件型）

> P1 条目同样五段完整；数据接入（t4 审计通过 + collector 扩展）后可升 P0。

### M8 LPR/社融信用脉冲 → 中期顺周期方向（月度）

- **① 核心理论**：信用周期先行论——政策利率（LPR）下调与社融扩张领先实体需求 1–2 个季度，领先工业品价格中期方向。可证伪命题：LPR 下调（或社融-M2 剪刀差转正）后 3 个月黑色/有色指数正收益频率显著高于基线。
- **② 市场模型**：月度状态 `c_t = 1(LPR_t < LPR_{t-1})` 与 `Δlog社融_t`；`E[r_{t+1:t+60}] = α + β₁·c_t + β₂·Δlog社融_t`（月频，60 日为近似 3 个月）。
- **③ 策略**：c_t=1 且社融扩张 → 顺周期品种（黑色/有色）趋势策略加过滤权重 +0.5；只做中期背景过滤，不做月度择时开仓。
- **④ 数据依赖**：akshare `macro_china_lpr`、`macro_china_shrzgm`、`macro_china_money_supply`（实测接口存在）→ **needs-extension**。
- **⑤ 证伪测试**：月度样本（约 90 期）walk-forward 20 期：方向命中 ≥ 60% 否则弃；2023 后信用-工业品脱钩段单列。

### M9 CPI/PPI 再通胀 regime → 商品配置权重（月度）

- **① 核心理论**：通胀传导与商品超额收益（Gorton-Rouwenhorst 2006：商品在通胀上行期跑赢）。可证伪命题：PPI 环比 3MMA 转正后 3 个月工业品板块收益 > 通缩期收益。
- **② 市场模型**：`π_t = sign(PPI环比3MMA_t)`；`z_t ∈ {再通胀, 平稳, 通缩}` 由 `π_t` 与 `CPI环比3MMA_t` 联合确定；板块权重 `w(z)` 查表。
- **③ 策略**：再通胀 → 有色/能化多头候选权重 ×1.5；通缩 → 全池多头降级、空头候选权重 ×1.0。
- **④ 数据依赖**：akshare `macro_china_ppi`、`macro_china_cpi_monthly` → **needs-extension**。
- **⑤ 证伪测试**：月度 walk-forward：象限切换后 3 月收益方向命中 ≥ 60%，否则弃。

### M10 增长-通胀象限投资时钟（月度 PMI/PPI 版）

- **① 核心理论**：经济周期相位决定资产相对收益（All-Weather/投资时钟）。
- **② 市场模型**：`g_t = sign(PMI_t − 50 的 3MMA)`、`π_t = sign(PPI环比3MMA)`；2×2 象限 → 配置映射（复苏=顺周期多、过热=资源/农产品多、滞胀=供给受限多+需求链空、衰退=宏观空）。
- **③ 策略**：象限过滤器 + 板块权重表（只过滤，定价仍由底层策略模型导出）。
- **④ 数据依赖**：akshare `macro_china_pmi`、`macro_china_ppi` → **needs-extension**。
- **⑤ 证伪测试**：月度 walk-forward 象限命中 ≥ 55%；连续 3 个季度失效 → 弃。日频代理版（5 锚点 change5d 版）已由 M5 覆盖，不得与本条混用（代理 ≠ 象限模型）。

### M11 政策事件驱动（降准/降息/重要会议）

- **① 核心理论**：预期差理论——政策对价格的冲击取决于实际-预期的差，而非政策本身方向。
- **② 市场模型**：事件日 t₀（公告）；`r_{t0+1:t0+3}` 的条件分布按"预期差符号"分组（宽松超预期/符合预期/不及预期）。预期差需要公开一致预期数据。
- **③ 策略**：仅"宽松超预期"组做多黑色脉冲（3 日持有）；"不及预期"组做空黑色。止损 1×ATR5。
- **④ 数据依赖**：政策公告结构化日历 + 一致预期 → **needs-extension**（公开信息，需人工/爬虫结构化；akshare 无直接接口）。
- **⑤ 证伪测试**：事件样本 < 40 → 不启用；分组收益 t 检验 p < 0.10。
- **备注**：降准/降息对 DR007 的影响已由 M1 的 s_t 部分吸收；本条目只处理"预期差"增量，避免与 M1 定价混用。

### M12 中美利差 → 人民币汇率压力 → 进口品种（扩展版）

- **① 核心理论**：利率平价/资本流动——中美利差收窄（或倒挂加深）→ 人民币贬值压力 → 进口成本型品种内盘相对偏强。
- **② 市场模型**：`spr_t = CN10Y_t − US10Y_t`；`E[ΔUSDCNH_{t+1:t+20}] = α + β·spr_t`（β<0）；再经 M2 的 β_cnh 传导到油粕。
- **③ 策略**：spr 快速收窄（Δ5d < −0.15pp）→ 油粕空头禁止 + 多头候选加权重。
- **④ 数据依赖**：CN10Y 与 US10Y 同表（akshare `bond_zh_us_rate` 含中国 10 年列）→ **needs-extension**（接口已实测存在，未接入管道）。
- **⑤ 证伪测试**：滚动 β 符号一致性 ≥ 70% 窗口，否则弃。

### M13 中国波指 QVIX → 风险偏好（期权隐波版）

- **① 核心理论**：投资者恐惧指数（Whaley 2000 的 VIX 思路移植到国内 50ETF 期权隐波）。
- **② 市场模型**：`v_t = QVIX 水平与 5 日变化`；`E[r_{顺周期,t+1:t+5}]` 与 `Δ5d QVIX` 负相关。
- **③ 策略**：QVIX 急升（≥ +5 点/5 日）→ 空头候选权重 ×1.5、多头禁止；回落后解除。过滤器角色，替代不可得的 VIX。
- **④ 数据依赖**：akshare `index_option_50etf_qvix`（实测接口存在）→ **needs-extension**。
- **⑤ 证伪测试**：与 M5 相同的 walk-forward 提升门槛；QVIX 数据历史长度不足 3 年则不启用。

## 5. 交付边界声明与下游建议

1. **数据契约草案（交 t4 逐条复核）**：M1–M7 的 P0 版全部只依赖 `macro-snapshot/macro-history + raw.json/daily + probability.json` 的既有字段；M8–M13 的 needs-extension 接口名与预期字段已在 0.2 节实测列明，请 t4 复核回填长度、更新频率、字段映射与未来函数风险。
2. **参数纪律**：本文所有模型参数（β、α̂、σ_z、κ、阈值 0.5pp/1.0%/0.20pp 等）均为**待标定初值**，标定只用信号日及以前数据；阈值必须经证伪测试后冻结，冻结后改动需重跑全部门禁。
3. **理论/模型/策略不可混用清单（交 t5）**：
   - M3 的实际利率 β 不得用于 M5/M7；M5 是过滤器不产生定价；M6 是 overlay 不产生方向；
   - M4 价差模型不得引入库存/利润变量（属 t2 基本面范围）；
