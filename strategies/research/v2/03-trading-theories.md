## 0. 口径、强绑定纪律与通用实盘约束

### 0.1 强绑定纪律（理论→模型→策略，不可混用）

1. **每条策略是不可拆分的绑定单元**：核心理论（可证伪命题，说明赚什么钱、为什么持续）→ 市场模型（状态变量 + 状态转移/条件分布公式）→ 策略（方向、入场、止损、目标、仓位全部由模型方程导出）。
2. **定价只能来自本策略的市场模型**：止损 = 理论失效点（模型状态被证伪的位置），目标 = edge 衰减点（模型预期收益衰减至成本以下的位置），仓位 = edge 强度（模型给出的条件期望/波动率比）。禁止借用其它策略的模型或参数定价。
3. **FinCoT / 日报驱动文本只作分析层输入**：仅可作过滤器（如"当日无新驱动"→ 禁用 TR-04），不参与定价、不产生目标价、不产生仓位。
4. **参数必须有来源**（domain-knowledge 或 frozen-calibration），禁止按样本内结果调参。凡"策略"实质上等于参数网格搜索而无模型支撑者，一律剔除（见 §10）。
5. **与 t1/t2 文件边界**：本文件只收录"交易系统"策略——由价格/波动率/量仓/期限价差的统计与微观结构模型定价的策略。产业供需驱动的基差、季节性、利润传导策略属 t2；宏观 regime 轮动属 t1。交易形态相似（例如都表现为价差交易）但定价模型不同者，不得混用（TR-07 的定价模型是仓储/资金成本均衡带，t2 基差策略的定价模型是供需失衡——两者不可互换止损/目标公式）。

## 1. TR-01 趋势延续（时间序列动量，状态过滤版）

**一句话**：在已确认的趋势状态中，用"突破新高 + 放量 + 持仓配合"证明趋势仍在加速时入场，赚趋势持续的钱。

### 1.1 核心理论（赚什么钱、为什么持续）

- **可证伪命题**：`E[r_{t+h} | sign(r_{t−L,t}) = +, s_t = U] > 0`，即在上升趋势状态中，未来 h 日条件期望收益为正；且该优势随 h 增大而衰减（动量半衰期）。
- **为什么持续**：信息扩散缓慢（投资者反应不足，价格逐步吸收基本面变化）+ 正反馈与资本再配置（趋势跟踪资金自我强化）+ 风险转移（套保盘在趋势中持续让渡风险溢价）。三类机制均在"状态 U 得到量仓确认"时最强，在无确认的漂移中不可靠——这是本策略不裸追趋势、必须叠加突破与量能确认的理论原因。
- **中国证据**：时间序列动量在中国商品期货市场显著存在（[Revisiting time series momentum in China's commodity futures market — Economic Modelling 2023](https://www.sciencedirect.com/science/article/abs/pii/S0264999323003346)，动量收益来源含流动性供给与套保压力）；经典文献 Moskowitz-Ooi-Pedersen (2012) 58 品种 1–12 个月动量显著；Hurst-Ooi-Pedersen (2017) 百年趋势跟踪证据。
- **仓库内部**：EMA20 趋势 + 突破在样本内唯一正向验证（`SIMPLE-MOMENTUM-RESULTS.md`：严格 17 笔 +1.54%、Sharpe 3.54，样本内探索性）。

### 1.2 市场模型（状态变量 + 条件分布 + 状态转移）

- 状态变量：趋势状态 `s_t ∈ {U(up), D(down), C(chop)}`，由双重指标确定：
  - 对齐：`close_t > MA20_t` 且 `close_t > MA60_t`（多；空头镜像）；
  - 斜率：`g_t = (EMA20_t − EMA20_{t−5}) / (5 × EMA20_{t−5})`（%/日），`g_t ≥ +0.3%/日` 为 U 态。
- 动量强度：`m_t = r_{t−20,t}`（过去 20 日收益率）。
- 条件收益分布（模型假设，供验证）：

  `r_{t+h} | s_t = U ~ N(μ_U · f(h), σ_t · √h)`，其中 `f(h)` 单调衰减且 `f(h) → 0`（动量半衰期 5–10 个交易日，与仓库 3d/5d 概率锥口径一致）；`μ_U` 正比于 `m_t`。
- 状态转移：`P(s_{t+1} = U | s_t = U) = q_UU`（高）；趋势失效事件 `F_t`：收盘跌回突破位下方 0.5×ATR5，或放量（量比 ≥ 1.5）收盘跌破 `MA20_t − 0.5×ATR5`。`F_t` 出现 → `s_t` 转出 U，即理论失效点。
- 信息确认：入场还需 `1{close_t > max(high_{t−20,…,t−1})} × 1{量比_t ≥ 1.2}`（突破 + 量能 = 信息进入市场的证据）。

### 1.3 策略（全部由 1.2 模型导出）

| 要素 | 规则 | 模型溯源 |
|---|---|---|
| 方向 | 多空对称；空头距涨停 < 1×ATR5 禁开（逼仓） | §0.3 |
| 入场触发 | U 态 ∧ 收盘突破 20 日高/低 ∧ 量比 ≥ 1.2；执行 T+1 开盘，跳空 > 0.5×ATR5 放弃 | 状态确认区 |
| 初始止损 | `min(入场价 ∓ 1.5×ATR5, 突破前 3 日极值 ∓ 0.25×ATR5)` 取更近 | 理论失效点 F_t 的前置版 |
| 失效退出 | 收盘触发 F_t → 次日开盘离场；连续 2 日量比 < 0.8（动能衰竭）→ 次日离场 | F_t |
| 目标 T1 | 2R 平 50% | edge 半衰期前锁定 |
| 目标 T2 | 3R 或 3d p95 上/下沿，先到者；余仓 2×ATR5 移动止损 | `f(h)` 衰减至成本以下 |
| 时间止损 | 10 个交易日未触及 T1 → 全平 | f(h) → 0 |
| 仓位 | `|g_t| ∈ [0.3%, 0.6%)` → 0.5R；`|g_t| ≥ 0.6%` → 1R（edge 强度分档）；单笔风险 ≤ 权益 1% | μ_U ∝ m_t |
| 加仓 | 浮盈 ≥ 1R 且再创 5 日新高/低 → +0.5 单位，最多 2 次；亏损仓绝不摊平 | 状态持续确认 |
| 持有 | 2–10 个交易日 | f(h) 半衰期 |

### 1.4 实盘约束核对

T+1 开盘执行（§0.2）；跳空 > 0.5×ATR5 放弃（§0.3）；空头距涨停 < 1×ATR5 禁开；换月日不作入场日；长假前按 §0.3 降仓；成本往返 ≈0.07%（按品种复核）。

### 1.5 数据依赖

`data/daily/<SYMBOL>.json`（OHLCV + OI）；长历史用 akShare `futures_main_sina`；均线/ATR/量比在库内推导；`config/symbols.json` 取乘数。无新增数据源。

### 1.6 证伪测试

- 交易级：F_t 触发即离场（已在规则内）。
- 策略级：≥200 笔、purged walk-forward、PF ≥ 1.2、95% CI 不含 0（§0.5）；对照三基线。
- **理论级证伪**：若"突破 + 量比 ≥ 1.2"子样本的扣成本收益 ≤ "无确认突破"子样本 → 信息确认机制无效，理论核心命题被证伪，本策略终止。
- 内部证据级别：**A−**（样本内正向 + 国内外文献，缺样本外验证）。

## 2. TR-02 波动率压缩 → 扩张突破（NR7/低 HV + 量能确认）

**一句话**：波动率压缩后第一根放量扩张 K 线启动短期趋势——不做方向预测，只做扩张方向跟随。

### 2.1 核心理论

- **可证伪命题**：在波动率压缩状态下（`HV%ile ≤ 30` 或 NR7），出现满足量能确认的扩张日 E_t 后，`E[r_{t+h} | E_t] > 0` 且该优势在 2–5 日内衰减至零。
- **为什么持续**：波动率聚集（volatility clustering）——压缩后的扩张是波动率状态转移的统计规律；突破触发止损单级联与趋势跟踪资金追入，形成短期正反馈；扩张方向的"信息含量"由量能确认过滤（防止把无信息的随机尖刺当突破）。
- **证据**：Crabel (1990) NR7 压缩/扩张；Bollinger (2002) 带宽挤压；仓库扫描器 Vol%ile/Vol× 字段可参数化该状态。

### 2.2 市场模型

- 波动率状态（GARCH 族聚集模型，用作状态定义而非参数拟合）：`σ²_{t+1} = ω + α·ε²_t + β·σ²_t`，压缩态 = `σ̂_t` 处于近 90 日低位（HV%ile ≤ 30）或 `TR_t = min(TR_{t−6..t})`（NR7）。
- 扩张事件：`E_t = 1{TR_t ≥ 2 × mean(TR_{t−5..t−1})} × 1{close_t 位于当日区间上 20% 或下 20%} × 1{量比_t ≥ 1.5}`。
- 条件收益（脉冲模型）：`r_{t+h} | E_t ~ N(μ_e · e^{−λh}, σ√h)`，λ 大（脉冲半衰期 2–5 日）→ 短持有、快兑现。
- 失效事件：收盘回到扩张日区间中点以内（扩张被回吐 50% = 假突破，E_t 的信息被证伪）。

### 2.3 策略（由 2.2 导出）

| 要素 | 规则 | 模型溯源 |
|---|---|---|
| 方向 | 扩张方向跟随；**禁止在扩张日反向抄底/摸顶** | 模型不含方向预测项 |
| 入场 | E_t 成立 → T+1 开盘（跳空 ≤ 0.5×ATR5）；保守档 T+1 收盘再确认、T+2 开盘 | E_t 确认 |
| 初始止损 | `min(入场价 ∓ 1×ATR5, 扩张日区间中点)` 取近 | 假突破证伪点 |
| 目标 T1 | 2R 平 50% | e^{−λh} 半衰期前 |
| 目标 T2 | 3d p95 上/下沿；余仓 1×ATR5 移动止损 | μ_e 衰减至成本以下 |
| 时间止损 | 5 个交易日未触及 T1 → 全平 | λ 大 |
| 仓位 | `TR_t/ATR5 ∈ [2,3)` → 0.5R；`≥ 3` → 1R（扩张强度分档） | μ_e ∝ 扩张幅度 |
| 加仓 | 浮盈 ≥ 1R 且连续 2 日收盘同向 → +0.5 单位，最多 1 次 | 状态持续 |
| 持有 | 2–5 个交易日 | 脉冲衰减 |

### 2.4 实盘约束核对

同 §0.3；扩张日若触及涨跌停 → 该日不作入场（E_t 的"量"被锁板扭曲）；跳空条款同 TR-01。

### 2.5 数据依赖

`data/daily/<SYMBOL>.json`（TR/ATR/HV%ile/量比在库内推导）；`probability.json` 提供 HV%ile 与 3d 锥。无新增数据源。

### 2.6 证伪测试

- 交易级：收盘回到扩张日区间中点 → 次日离场。
- 策略级：≥200 笔、walk-forward、PF ≥ 1.2、三对照（§0.5）。
- **理论级证伪**：若"压缩态 + 扩张确认"子样本收益 ≤ "非压缩态扩张"子样本 → 波动率状态转移机制无效，终止。内部反面证据提示（`SIMPLE-MOMENTUM-RESULTS.md`：裸 Donchian 邻近度失败）已通过"压缩前置 + 量能确认"纳入模型，但必须通过理论级证伪方可长期启用。
- 证据级别：**C**（假设性，未回测；v1 PB-02 反面证据要求本策略默认谨慎、验证后启用）。

## 3. TR-03 趋势回踩续势（趋势 + OU 噪声分解模型）

**一句话**：趋势中不追突破，等回踩至动态支撑带出现反转确认再入场——赚"噪声回归 + 趋势漂移"的叠加，入场距止损更近、赔率更优。

### 3.1 核心理论

- **可证伪命题**：在 U 态中，价格回踩至 MA20 带（噪声分量 `x_t` 显著为负）后出现反转确认 K 线时，`E[r_{t+h}] > 0`，且该优势来自噪声回归项 `θ·|x_t|`，随 `x_t → 0` 耗尽。
- **为什么持续**：趋势由基本面/资金流驱动（慢变量），短期价格围绕趋势的偏离由流动性冲击造成（快变量、均值回归）；回踩 = 趋势跟随者的入场成本最优区，确认 K 线 = 噪声已耗尽、趋势恢复支配。
- **证据**：Edwards & Magee 趋势线回踩经典；Raschke & Connors (1996) "Holy Grail" 形态（ADX<30、20 日低点入场、前低止损、20 日高点离场）；仓库雷达 Q2 直接提供 MA20/MA60 对齐状态。

### 3.2 市场模型

- 分解模型：`p_t = c_t + x_t`，其中 `c_t` 为趋势分量（U 态下带漂移 `μ_c` 的随机游走），`x_t` 为 OU 噪声：

  `dx_t = −θ·x_t dt + σ·dW_t`，`E[x_{t+h} | x_t] = x_t·e^{−θh}`。
- 回踩条件（多）：`low_t ≤ MA20_t + 0.25×ATR5`（触及带）；反转确认：`close_t > high_{t−1}`；量比 0.8–1.5（缩量回踩 = 噪声而非趋势反转）。
- 状态转移：`F_t`（同 TR-01：放量跌破 MA20 − 0.5×ATR5）= 趋势分量 `c_t` 下移的证伪事件 → 离场。
- 条件期望：`E[r_{t+1} | 回踩 ∧ 确认] = μ_c + θ·|x_t|·e^{−θ} − 成本`；edge 主要由 `θ·|x_t|` 贡献 → **止损距离必须 ≤ 1.5R**，否则噪声 edge 覆盖不了成本。

### 3.3 策略（由 3.2 导出）

| 要素 | 规则 | 模型溯源 |
|---|---|---|
| 方向 | 多空对称；空头反抽要求 OIΔ ≤ +2%（规避逼仓），多头要求 OIΔ ≥ −2% | §0.3 + 状态条件 |
| 入场 | U 态（close>MA20>MA60 或 MA20 斜率向上）∧ 触及 MA20±0.25×ATR5 带 ∧ 反转确认 K；T+1 开盘，跳空 > 0.75×ATR5 放弃 | 噪声 x_t<0 + 确认 |
| 初始止损 | 回踩极值 ∓ 0.25×ATR5；**止损距离 > 1.5R → 放弃该笔** | edge = θ·\|x_t\| 有限 |
| 失效退出 | 收盘 < MA20 − 0.5×ATR5 且量比 ≥ 1.5（放量破位 = c_t 下移）→ 次日开盘离场 | F_t |
| 目标 T1 | 前期波段高/低点或 3d p68 上/下沿，先到者，平 50% | x_t → 0 |
| 目标 T2 | 2R–3R；余仓 1×ATR5 移动止损 | 趋势漂移 μ_c 部分 |
| 时间止损 | 8 个交易日未触及 T1 → 全平 | θ 衰减 |
| 仓位 | `|x_t|/ATR5 ∈ [0.5,1)` → 0.5R；`≥ 1` → 1R | θ·\|x_t\| 强度 |
| 加仓 | 突破 T1 且量比 ≥ 1.2 → +0.5 单位（止损上移 1×ATR5），最多 1 次 | 状态升级 |
| 持有 | 3–8 个交易日 | — |

### 3.4 实盘约束核对

T+1 开盘（§0.2）；跳空 > 0.75×ATR5 放弃——跳空直接越过入场带说明噪声已释放完毕、edge 消失，不追（§0.3）；其余同 §0.3。

### 3.5 数据依赖

`data/daily/<SYMBOL>.json`（MA/ATR/OIΔ/量比库内推导）；`config/symbols.json`。无新增数据源。

### 3.6 证伪测试

- 交易级：F_t 离场规则（在规则内）。
- 策略级：≥200 笔、walk-forward、PF ≥ 1.2、三对照（§0.5）。
- **理论级证伪**：若"回踩 + 反转确认"子样本收益 ≤ "回踩无确认"子样本 → 噪声耗尽确认无效；若止损距离 > 1.5R 的子样本 PF < 1 → 噪声 edge 定价正确性被证伪，收紧距离门槛。
- 证据级别：**B**（经典文献与行业通行，本仓库未直接回测）。

## 4. TR-04 极端偏离均值修复（regime 条件 OU；仅限低波动 chop 态）【P1】

**一句话**：无新驱动、低波动品种价格偏离 MA20 达 2×ATR5 时逆向回归均线——赚流动性冲击的修复溢价；模型要求先判定"chop 态"，趋势态禁用。

### 4.1 核心理论

- **可证伪命题**：在 `s_t = chop` 且 `x_t = p_t − MA20_t ≤ −2×ATR5` 时，`E[r_{t+h} | x_t] > 0`（h=1–5 日）；同一信号在趋势态或高波动态无优势甚至为负。
- **为什么持续**：短期反转/流动性供给溢价——做市与逆向资金吸收过度反应换取风险溢价（Lo & MacKinlay 1990 短期反转；Nagel 2012 流动性供给回报）；但该溢价只存在于"无信息驱动"状态：趋势态下极端偏离是趋势本身，回归 = 接刀。
- **内部反面证据**：`SIMPLE-MOMENTUM-RESULTS.md` 显示本仓库高波动品种动量 > 均值回归 → 本策略**限定 HV%ile ≤ 60 的 chop 态**并标 P1，先过子样本验证。
- **补充证据**：中国商品期货存在显著短期反转效应（[我国商品期货市场动量效应与反转效应实证研究](https://search.napstic.cn/literature/periodical/010nfjr201504007)）；日内反转效应在 [Is there an intraday reversal effect in commodity futures? Evidence from China](https://www.sciencedirect.com/science/article/abs/pii/S0927538X24002865) 中有记录（支持"过度反应后修复"机制，本策略为日线级应用）。

### 4.2 市场模型

- 两态 HMM：`s_t ∈ {T(trend), Chop}`；chop 态下 `x_t` 为 OU：`dx_t = −θ·x_t dt + σ·dW_t`，`E[x_{t+h}|x_t] = x_t·e^{−θh}`。
- chop 态判定（过滤器，非定价）：`HV%ile_t ≤ 60` ∧ 当日无新驱动（FinCoT Q1 驱动为空/旧，仅作分析层过滤）∧ `|OIΔ_t| ≤ 5%`。
- 入场：`x_t ≤ MA20_t − 2×ATR5`（多；空头镜像），且当日未触及跌停（锁板 = 极端仍在加深）。
- 失效：`|x_t|` 扩至 3×ATR5（θ≈0，模型错误）或新驱动出现（s → T）或 HV%ile 升破 90。

### 4.3 策略（由 4.2 导出）

| 要素 | 规则 | 模型溯源 |
|---|---|---|
| 方向 | 多空对称；多头要求所在板块当日上涨广度 ≥ 30%（避免系统性下跌中接刀） | chop 判定 |
| 入场 | 上述条件 → T+1 开盘；跳空 > 0.5×ATR5 放弃（跳空加剧 = 极端加深，禁止接刀） | x_t 阈值 |
| 初始止损 | `min(入场价 ∓ 1×ATR5, 极值价 ∓ 0.5×ATR5)` 取近 | θ≈0 失效点 |
| 失效退出 | 新驱动出现 / HV%ile > 90 → 立即离场 | s → T |
| 目标 T1 | MA20（x=0）平 50% | edge 耗尽点 |
| 目标 T2 | 2R 全平 | 超出 OU 模型 |
| 时间止损 | 5 个交易日 | θ 衰减 |
| 仓位 | 固定 0.5R，**禁止加仓**；浮盈 1R 后止损移至成本 | 逆势单次仓 |
| 持有 | 1–5 个交易日 | — |

### 4.4 实盘约束核对

跌停日禁开；跳空 > 0.5×ATR5 放弃；长假前禁用（隔假跳空 = 新信息）；其余同 §0.3。

### 4.5 数据依赖

`data/daily/<SYMBOL>.json`；`probability.json`（HV%ile）；run artifacts 驱动文本（FinCoT 分析层，仅过滤）；`data/sector/<SECTOR>.json`（上涨广度）。无新增数据源。

### 4.6 证伪测试

- 交易级：驱动/HV 失效条件（在规则内）。
- 策略级：≥200 笔、walk-forward、PF ≥ 1.2、三对照（§0.5）。
- **理论级证伪**：分 HV%ile 子样本检验——若 HV%ile ≤ 60 子样本 PF < 1.2 → chop 态回归溢价在本市场不成立，终止；若 HV%ile > 60 子样本显著亏损 → 佐证 regime 条件必要性（同时验证模型而非仅参数）。
- 证据级别：**C**（未回测 + 内部反向证据提示，仅限低波动子集试验）。**P1（仅参考）**：依赖"chop 态判定"的稳健性，需先通过证伪再升 P0。

## 5. TR-05 区间边界反转 + 突破移交（两态区间模型）

**一句话**：低波动明确箱体内做边界回归（A 模式）；箱体被放量突破则移交趋势策略（B 模式）——把"假突破"变成模型内的状态转移事件。

### 5.1 核心理论

- **可证伪命题**：`s_t = range` 时，触及箱体边界后 `E[下一日回到箱内 | 触及] = p_R > 1/2`，边界反向交易的期望收益 = `(w/2)·(2p_R − 1) − 成本 > 0`；放量突破后 `P(s → trend)` 显著升高。
- **为什么持续**：无信息均衡下，价格由库存/流动性供需在箱体内往返（两向流动性供给），边界是交易拥挤区、回归力最强；突破 = 信息事件，状态切换由量能确认。
- **反面证据处理**：v1 PB-06 引用 `SIMPLE-MOMENTUM-RESULTS.md`——纯边界位置不预测方向（Donchian 邻近度失败）→ **A 模式默认停用，仅 B 模式（突破移交）启用**；A 模式须通过"箱内回归率 ≥ 60% 且扣成本 PF ≥ 1.2"验证后方可启用。

### 5.2 市场模型

- 状态：`s_t ∈ {R(range), T(trend)}`；R 判定：箱体 `[L_t, H_t]`（近 20 日高/低），箱宽 `w_t = H_t − L_t ≥ 2.5×ATR5`，`HV%ile ≤ 40`，近 20 日 ≥ 4 次触及边界。
- R 态边界回归：`E[r_{t+1} | 触及上沿] ≈ −(w/2)·(2p_R − 1)`（下沿镜像）；`p_R` 为待估计参数（验证样本校准后冻结）。
- 状态转移：`B_t = 1{close_t > H_t} × 1{量比_t ≥ 1.5}`（或下破镜像）→ `P(s_{t+1} = T | B_t)` 显著高于无确认突破；B_t 后移交 TR-01/TR-02 定价（注意：移交的是**入场与持仓管理**，TR-05 自身不对突破后行情定价——避免跨策略混用定价模型）。

### 5.3 策略（由 5.2 导出）

| 要素 | A 模式（边界回归，默认停用） | B 模式（突破移交，启用） |
|---|---|---|
| 方向 | 触及上沿 → 空；下沿 → 多 | 突破方向跟随 |
| 入场 | 触及边界当日收盘仍在箱内 → T+1 反向入场 | 收盘突破 + 量比 ≥ 1.5 → T+1 入场，移交 TR-01/02 管理 |
| 执行 | T+1 开盘；跳空 > 0.5×ATR5 放弃 | 同左 |
| 止损 | 边界外 0.25×ATR5（出箱 = R 态证伪） | 1×ATR5（按 TR-02） |
| 目标 | 对侧边界；入场前必须满足潜在盈利 ≥ 1.5R | 箱高 1:1 投影或 2R，先到者 |
| 仓位 | 0.5R，禁加仓 | 按 TR-02 扩张强度分档 |
| 持有 | 1–4 日 | 5–20 日 |
| 失效 | 连续 2 日收盘在箱外 → 区间失效离场 | 按 TR-01/02 失效规则 |

### 5.4 实盘约束核对

同 §0.3；箱体边界若靠近涨跌停 → 边界回归禁开（锁板扭曲 p_R）；长假前出箱逻辑停用。

### 5.5 数据依赖

`data/daily/<SYMBOL>.json`（箱体/ATR/HV%ile/量比库内推导）。无新增数据源。

### 5.6 证伪测试

- 交易级（A）：连续 2 日箱外 → 离场。
- 策略级：B 模式 ≥200 笔、walk-forward、PF ≥ 1.2、三对照（§0.5）。
- **理论级证伪**：箱内触及后 1 日回归率 `p̂_R < 0.6` 或 A 模式扣成本 PF < 1.2 → 边界回归溢价不成立，A 模式永久停用（B 模式不受影响——两模式模型不同，禁止合并检验）。
- 证据级别：**C**（未回测；B 模式与 TR-02 共享反面证据风险）。**P0（仅 B 模式）/ A 模式停用待验证**。

## 6. TR-06 事件冲击确认（事件分解模型：持久信息 vs 瞬时情绪）

**一句话**：重大消息引爆的放量大阳/大阴线，当日不追，等"资金确认"或"回踩不破"再入场——只交易冲击的持久分量，过滤一次性情绪。

### 6.1 核心理论

- **可证伪命题**：事件日 D（`|r_D| ≥ max(2×ATR5, 3%)` ∧ 量比 ≥ 2 ∧ 存在可识别驱动）后，冲击可分解为持久信息分量 `A·e^{−λk}` 与瞬时情绪分量 `S·e^{−γk}`（γ ≫ λ）；"确认式/回踩式"入场组合对持久分量的捕获优于当日追入，且优势 ≥ 0.5R。
- **为什么持续**：信息处理需要时间（反应不足 → 事件后漂移；Hong & Stein 1999 统一理论），当日情绪冲高会回吐（过度反应）；不同冲击类型持续性不同（Kilian 2009：供给冲击持续、需求冲击易反转）→ "等确认"是模型内在要求而非保守偏好。
- **证据**：Sumner & Mueller (1989) 农产品消息冲击事件研究；Kilian (2009) "Not All Oil Price Shocks Are Alike"（AER）；仓库 20260827 RM0 案例（黑海粮道扰动 + Q4 站稳 2314 + 持仓续增）与本结构一致。

### 6.2 市场模型

- 事件日判定：`D = 1{|r_D| ≥ max(2×ATR5, 3%)} × 1{量比_D ≥ 2} × 1{Q1 存在可识别驱动}`。
- 冲击分解：`r_{D+k} = A·e^{−λk} + S·e^{−γk} + ε`，γ ≫ λ；持久分量主导时 `E[r_{D+k}|确认] ≈ A·e^{−λk}`。
- 持久分量确认信号（多）：`close_{D+1..D+2} > high_D` ∧ `OIΔ ≥ +2%`（资金进场，A > 0 概率高）；回踩变体：回撤 ≤ 事件区间 50% ∧ 连续 2 日收盘站稳事件区间中点上方（S 分量已释放、A 未衰减）。
- 失效：收盘回到事件前 5 日区间内（A = 0，事件影响消退）或多头 OIΔ 转负。

### 6.3 策略（由 6.2 导出）

| 要素 | 确认式 (a) | 回踩式 (b) |
|---|---|---|
| 入场 | D 后 T+1/T+2 收盘 > high_D ∧ OIΔ ≥ +2% → 次日开盘 | 回撤 ≤ 50% 区间 ∧ 2 日站稳中点上方 → 第 3 日开盘 |
| 执行 | 开盘入场；跳空 > 0.75×ATR5 放弃 | 同左 |
| 初始止损 | low_D − 0.25×ATR5 | 事件区间中点 − 0.25×ATR5 |
| 目标 T1 | 3d p95 上/下沿，平 50% | 同左 |
| 目标 T2 | 2× 事件区间投影或 3R，先到者 | 同左 |
| 时间止损 | 8 日未触及 T1 → 全平 | 同左 |
| 仓位 | 0.5–1R（事件幅度 `|r_D|/ATR5` 分档） | 同左 |
| 加仓 | 浮盈 ≥ 1R 且 OIΔ 维持同向 → +0.5 单位，最多 1 次 | 同左 |
| 持有 | 2–8 日 | 2–8 日 |

方向适配：多空对称；空头距涨停 < 1×ATR5 禁开（事件驱动下逼仓概率更高）；多头要求 OIΔ ≥ +2%，空头不强制 OI 条件（多杀多亦有效）。

### 6.4 实盘约束核对

事件日若封停板 → 次日开盘跳空大概率 > 阈值 → 自然放弃或按锁板规则处理；隔周持有按 §0.3 模型重估；其余同 §0.3。

### 6.5 数据依赖

`data/daily/<SYMBOL>.json`（事件判定 + OIΔ）；run artifacts Q1 驱动文本（FinCoT 分析层，仅作事件识别过滤器）；`probability.json`（3d 锥）。无新增数据源。

### 6.6 证伪测试

- 交易级：收盘回到事件前 5 日区间 → 次日离场；多头 OIΔ 转负 → 次日离场。
- 策略级：≥100 笔（事件样本天然稀疏）、walk-forward、PF ≥ 1.2、三对照（§0.5）。
- **理论级证伪**：事件日当日追入 vs 本策略延迟入场的样本外收益差 < 0.5R → "确认等待"无增益，冲击分解模型的 λ/γ 区分被证伪，终止。
- 证据级别：**B**（案例一致 + 外部事件研究，规则本身未回测）。

## 7. TR-07 跨期价差回归（仓储/资金成本均衡带模型）【P1 → 待 t4 审计升 P0】

**一句话**：近远月价差偏离 carry 均衡带极端分位时做收敛交易——赚价差向仓储成本/便利收益均衡的回归，双腿对冲掉单边方向风险。

### 7.1 核心理论

- **可证伪命题**：价差 `s_t = F_far − F_near` 在 carry 均衡带内均值回归：`E[Δs | z_t ≤ −2] > 0`（买近卖远方向），且回归速度 θ > 0。
- **为什么持续**：无套利携带成本约束——contango 价差上限 = 仓储 + 资金 + 交割成本（Working 1949；Brennan 1958 供给仓储理论），backwardation 由便利收益支撑；价差极端分位 = 库存/资金极端状态的体现，产业与套利资金共同修复。期限结构风险溢价在中国商品市场可投资、持续存在（[Investable commodity premia in China — JBF 2021](https://www.sciencedirect.com/science/article/abs/pii/S0378426621000856)；Szymanowska et al. 2014 风险溢价分解）。
- **与 t2 基差策略的边界**：t2 的基差/月差策略由产业供需模型定价（驱动 = 库存拐点）；本策略由 carry 成本均衡带定价（驱动 = 价差分位 + 均衡带边界）。两者不可混用止损/目标公式。

### 7.2 市场模型

- 均衡带：`−(c_storage + c_fin + c_delivery) ≤ s_t ≤ CY_max`（CY 为便利收益上界）；带参数因品种而异（贵金属以资金成本为主，黑色以仓储/交割为主）。
- 价差 OU 模型：`ds_t = θ(μ̂ − s_t)dt + σ·dW`；`z_t = (s_t − μ̂_{120}) / σ̂_{120}`（滚动 120 日校准，冻结后验证）。
- 入场：`|z_t| ≥ 2` ∧ 近月距交割 > 20 日 ∧ 两腿成交量均高于品种流动性阈值。
- 失效：`|z_t| ≥ 3`（θ≈0）或结构性变化（交割规则/政策/工艺改变导致均衡带平移——即"中枢迁移"，须先验识别而非事后解释）。

### 7.3 策略（由 7.2 导出）

| 要素 | 规则 | 模型溯源 |
|---|---|---|
| 方向 | `z ≤ −2` → 买近卖远（价差收敛上行）；`z ≥ +2` → 卖近买远 | OU 回归方向 |

## 8. TR-08 跨品种/板块相对强弱价差（协整 OU 模型）【P1】

**一句话**：产业关联两腿价差偏离协整均衡 2σ 时做相对价值回归——赚产业链替代/成本关系约束下的价差收敛，双向对冲系统性风险。

### 8.1 核心理论

- **可证伪命题**：存在 β 使 `z_t = ln P_A − β ln P_B` 为平稳 OU 过程；`E[Δz | z ≥ 2σ] < 0`（做空 A 做多 B 方向），且该回归由真实产业关联（替代、加工成本、宏观属性差）维持。
- **为什么持续**：产业均衡约束（替代关系/成本曲线）使价差长期有界；价差偏离由短期资金错配造成，随供需与套利资金回归；配对交易是成熟范式（Gatev-Goetzmann-Rouwenhorst 2006）。
- **与 t2 的边界**：t2 的产业利润策略由利润→开工传导模型定价；本策略由价差协整统计模型定价，产业逻辑仅用于**选择配对与判定中枢迁移**，不用于定价。不可混用。

### 8.2 市场模型

- 协整：`z_t = ln P_A − β̂ ln P_B`，β̂ 由滚动窗口 OLS 校准并冻结（禁止样本内迭代优化）；`z_t` 服从 OU：`dz = −θ z dt + σ dW`。
- 入场：`|z_t| ≥ 2σ̂` ∧ 两腿均在品种池活跃列表（`config/symbols.json active=true`）∧ 板块相对强弱确认（`sector-snapshot` leaders/laggards 方向与价差回归方向一致——确认逻辑非定价）。
- 失效：`|z_t| ≥ 3σ̂` 或 β̂ 结构断裂（滚动残差 ADF 检验失效 = 产业关系改变）。

### 8.3 策略（由 8.2 导出）

| 要素 | 规则 | 模型溯源 |
|---|---|---|
| 方向 | `z ≥ +2σ̂` → 空 A 多 B；`z ≤ −2σ̂` → 多 A 空 B | OU 回归 |
| 入场 | T+1 两腿同步；任一腿跳空 > 0.5×ATR5 放弃 | 同步性 |
| 止损 | `|z| ≥ 3σ̂` 或 β̂ 断裂 → 双腿同平 | 模型失效 |
| 目标 | `z → 0 ± 0.5σ̂` | edge 耗尽 |
| 仓位 | 0.5–1R（R 按价差 σ̂ 计）；双腿 β̂ 对冲比例建仓 | σ̂ 定价 |
| 持有 | 5–20 个交易日 | θ 相关 |
| 加仓 | 禁止 | — |

### 8.4 实盘约束核对

双倍保证金；双腿同步滑点差异（相对价值对执行偏差敏感，滑点预算放宽至 0.1% 往返）；单腿逼仓 → 整体离场；长假前按 §0.3。

### 8.5 数据依赖

`data/daily/<SYMBOL>.json` 两腿（库内）；长历史用 akShare 主力连续；`data/sector/<SECTOR>.json`（相对强弱确认）；`config/symbols.json`。**t4 审计项**：协整校准所需历史长度（≥500 bars？）与两腿同窗口对齐。

### 8.6 证伪测试

- 交易级：`|z| ≥ 3σ̂` 离场（在规则内）。
- 策略级：≥100 笔、walk-forward、PF ≥ 1.2、对照：单腿 always-long 对照。
- **理论级证伪**：样本外滚动窗口残差 ADF 检验通过率 < 80% → 协整关系不稳定，终止该配对；剔除中枢迁移事件后仍亏损 → 回归溢价不成立。
- 证据级别：**C**（范式成熟但本仓库无价差历史数据积累）。**P1**：需自建价差序列 + 冻结协整参数，t4 审计后决定是否升 P0。
