# 24 预注册实验协议 —— 证伪/探针的统计与执行规范

> 目的：修正此前“阈值拍脑袋、探针与策略脱节、多重检验无预算”的问题。
> 本协议自 2026-08-28 起适用于所有新证伪实验与探针实验。

## 1. 假设注册（实验前必须写死）
每个实验必须登记：
- `hypothesisId`、`strategyId`（如适用）
- 理论命题与备择假设
- 精确实现的公式/条款引用（strategy-library-v2.json 字段路径）
- 数据范围、样本期、universe、成本、seed
- 主统计量与决策阈值
- 停止规则与失败归因规则

注册后不得修改；修改视为新实验。

## 2. 统计阈值（由成本与基线推导，不再拍脑袋）

### 2.1 收益阈值
- 净收益 = 毛收益 − 成本（单腿 0.07% 往返，双腿 0.14%）
- 通过条件：`mean(net) > 0` 且 `95% CI 下界 > 0`

### 2.2 命中率阈值
- 基准命中率：方向随机基线 ≈ 50%（或同 entries 随机方向基线的实测值）
- 通过条件：策略命中率相对基准的**单侧二项检验 p < α_adj**，而非固定 55%
- 只有当样本功效 ≥80% 能检出“+3pp 命中率差异”时，命中率检验才具有效性；否则标注低功效、不下结论

### 2.3 多重检验预算
- 每轮最多注册 **3 个主假设**
- 族错误率 FWER=0.05，Bonferroni：单假设 α_adj = 0.05 / 3 ≈ 0.0167
- 探针与证伪共享预算；候补池批量筛选不产生统计结论

### 2.4 样本充分性
- 策略级主检验：n ≥ 200（事件类 n ≥ 100），且预注册功效计算 ≥80%
- 未达样本 → `insufficient_sample`，不得 retired

## 3. Adapter 保真度前置
- 任何策略在通过 `23-fidelity-review.md` 的 F-A..F-H 前，不得进入统计判定
- 未实现条款必须 `not_implemented`，状态保持 `not_evaluable`

## 4. 失败归因规则
证伪结果必须区分：
- `falsified`：保真实现 + 统计门槛触发 + 理论级证伪成立
- `strategy_gate_failed`（v1.1 新增，2026-08-29 TR-01 判例）：保真实现 + 策略级门禁未过（PF/CI/年份/基线）+ 理论级未证伪 → suspended，**不得 retired**
- `not_evaluable`：实现或样本/事件设置存在缺陷
- `untested`：数据前置未满足
- `insufficient_sample`：实现保真但样本不足

注：F-A..F-H 中个别条款因数据契约缺口标 `not_implemented` 时，若该条款不在信号/定价链上，
须在复跑报告中给出影响评估并提请队长裁定豁免；队长批准后复跑结论才有效。

## 5. 结果发布
- 实验输出必须包含：注册快照、adapter 保真度检查表、数据校验、原始结果 JSON、复现命令
- 任何事后修改阈值的结论无效
