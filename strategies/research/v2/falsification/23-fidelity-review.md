# 23 Adapter 保真度审查 —— 证伪结论有效性的前置门槛

> 结论：当前 8 条策略中，只有 TR-03/EC-01 的证伪证据可接受；其余 5 条因 adapter 实现偏差或实验设置缺陷，标记 `not_evaluable`，FS-02 标记 `untested`。
> 规则：在以下保真度清单逐项通过前，不得对任何策略新增 retired/suspended 结论。

## 1. 保真度验收清单（每条策略都必须逐项通过）

| # | 检查项 | 说明 |
|---|---|---|
| F-A | 市场模型公式 | adapter 使用的公式必须与 strategy-library-v2.json `marketModel.formulas` 编号一一对应，不允许近似公式 |
| F-B | 信号/入场 | 触发条件、方向门、事件/状态定义必须逐字对应库内条目；简化代理一律不视为实现 |
| F-C | 止损/目标 | 止损=理论失效点、目标=edge 衰减点的模型公式必须精确实现；禁止用固定 R 替代结构位 |
| F-D | 仓位/加减仓 | position 分档、加仓、风险预算必须实现；未实现不得宣称已执行该策略 |
| F-E | 执行条款 | T+1 开盘/收盘语义、跳空、涨跌停、换月剔除、停板数据、成本（单腿/双腿）必须与 asOfContract 一致 |
| F-F | 数据口径 | 只用 GA 数据 + 数据契约字段；PIT 硬守卫；无未来函数 |
| F-G | 证伪测试 | 每条 falsificationTests 的统计量、阈值、三基线、理论级测试必须原样执行，不替换代理 |
| F-H | 失败可归因 | 任何无法实现的条款必须标 `not_implemented` 并让该策略保持 `not_evaluable`，不得继续判 retired/suspended |
