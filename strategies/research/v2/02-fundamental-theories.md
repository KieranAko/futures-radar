## 2. P0 策略条目

### FS-01 交易所库存分位 + 库存拐点（库存周期）

- **优先级**: P0（库存历史需增量积累，见数据依赖）
- **适用品种**: 东财库存覆盖∩仓库活跃池: RB HC I J JM SM SF SS AO / CU AL ZN PB NI SN / M Y P A B C CS RM OI CF SR AP CJ JD LH / TA MA EG PP L V EB SA FG UR PF SH PX RU BR SP BU FU PG
- **核心理论（可证伪命题）**:
  - F1: 库存水平处于历史低分位（`inv_pct ≤ 0.2`）时，未来 20 个交易日超额收益显著为正（低库存 → 便利收益高 → 现货溢价与风险溢价抬升，Working 1949；Gorton-Hayashi-Rouwenhorst 2013 证明库存是期货风险溢价的首要基本面来源）。
  - F2: 库存处于高分位（`inv_pct ≥ 0.8`）**且**已确认累库（`Δinv5 > 0`）时，未来 20 日超额收益显著为负（主动补库尾声 → 供给过剩确认 → 价格下行）。
  - 前提: 无显性供给冲击窗口（政策限产/重大检修/事故公告——见已知反面证据）。
- **市场模型**:
  ```
  inv_pct_t  = Rank(inv_t | 过去250个交易日库存) ∈ [0,1]
  Δinv5_t    = inv_t − inv_{t−5}                      # 库存 5 日变动
  signal_t   = +1  if inv_pct_t ≤ 0.2
             = −1  if inv_pct_t ≥ 0.8 and Δinv5_t > 0
             =  0  其他
  E[ret_{t→t+20} | signal] = β̂ × (0.5 − inv_pct_t)    # β̂: 品种内滚动回归斜率（待标定）
  ```
  初期数据不足 250 日时: 窗口 = min(250, 可用天数)，且该品种标记 `short-history`，信号降级为观察。
- **策略**:
  - 方向: signal=+1 → 多；signal=−1 → 空。
  - 入场: T 日收盘触发，且 `close ≥ MA20`（多）/`close ≤ MA20`（空）（趋势过滤，防左侧接刀）。
  - 止损: ① 价格 1.5×ATR5 反向；② 库存拐点反向确认（多头遇 `inv_pct > 0.5` 且 `Δinv5 > 0` → 平）。先到先平。
  - 目标定价（模型导出）: `P_target = P_entry × (1 + β̂ × (0.5 − inv_pct_entry))`，即库存分位回归中位对应的隐含价；β̂ 由品种内滚动回归（ret_20d ~ inv_pct）标定、冻结、样本外验证。禁用固定百分比止盈。
  - 时间退出: 20 个交易日强制评估。
- **数据依赖**:
  - `futures_inventory_em(symbol=中文名)` — 实测 2026-08-27 返回 72 行（`日期/库存/增减`）；74 品种映射（§1.1）。**需新增增量采集器**（仿 `collector/incremental-cache.cjs` 模式）每日积累，≥250 日后进入完整标定。
  - 行情腿: `data/daily/{SYM}0.json`（MA20/ATR5）。
  - 库存口径声明: 东财口径为交易所库存/注册仓单，**不等于全社会库存**（螺纹社会库存需 Mysteel 付费 → 剔除，§4 X-02）；策略有效性仅在"交易所库存是供需的可靠代理"品种上成立（标定阶段逐品种检验）。
- **证伪测试**:
  - (a) 库存历史 ≥3 年后: `inv_pct` 与未来 20 日收益的 Spearman ρ 95% CI 含 0 → 证伪 F1/F2；
  - (b) 覆盖品种等权组合，扣除 0.07% 往返成本后: 夏普 < 0.5 或 20 日胜率 < 52% → 停用；
  - (c) 品种级: >50% 品种单品种不显著 → 剔除不显著品种，保留显著子集（子集名单写入策略库）。
- **已知反面证据（必须写入策略库）**: 2023–2024 纯碱——库存高位上行但价格因供给扰动大涨，F2 空头侧失效；2016–2017 供给侧改革期，螺纹交易所库存与社会库存背离，信号失准。→ 策略库实现时需显性供给冲击事件过滤层（复用 FS-09 政策/事件日历）。
- **证据来源**: Working, H. (1949), "The Theory of Price of Storage", AER — https://www.jstor.org/stable/1810370 ；Gorton, Hayashi & Rouwenhorst (2013), "The Fundamentals of Commodity Futures Returns", Review of Finance — https://academic.oup.com/rof/article/17/1/35/1598479 ；akshare 库存文档 — https://raw.githubusercontent.com/akfamily/akshare/main/docs/data/futures/futures.md
- **成熟度**: B（理论 A 级，国内品种样本内验证待做）
- **与 FinCoT 边界**: FinCoT 方向仅作冲突否决；入场/目标均由上式导出。

### FS-02 基差分位回归（现货–期货收敛）

- **优先级**: P0（数据今日即可得，含 180 日分布锚）
- **适用品种**: 生意社基差覆盖∩活跃池: RB HC I J JM / M Y P RM OI A B C CS CF SR / TA MA EG PP L V EB SA FG UR PF SH PX / CU AL ZN PB NI SN AU AG / FU BU RU SP SS BR / SI LC（SC、EC 无现货基差 → 不适用）
- **核心理论（可证伪命题）**:
  - F1: 基差率 `br = (S−F)/S` 为平稳均值回归序列；处于极端分位（|z|≥1.5）后，20 日内基差向 180 日中枢回归的概率显著 > 0.5（Theory of Storage: 基差 = 便利收益 − 持有成本，Kaldor 1939 / Working 1949；Fama & French 1987 证明基差对期货收益有预测力）。
  - F2: 期货深度贴水（z≤−1.5，现货强升水）时，收敛以"期货向现货靠拢"为主 → 期货端做多收益为正；期货深度升水（z≥+1.5）→ 期货端做空。收敛方向不对称性本身纳入证伪检验。
- **市场模型**:
  ```
  br_t = (S_t − F_t)/S_t          # 直接用 akshare dom_basis_rate（主力合约口径，无量纲比率）
  # 口径修正（t8 审查 F-1）: z 必须全程使用比率域统计量。
  # futures_spot_price_previous 的「180日主力基差 最高/最低/平均」是绝对基差（元/吨），
  # 不可与 br_t 直接混算；须先除以触发日现货价转比率域：
  μ̂ = b̂_mean/S_t ; σ̂ = (b̂_hi − b̂_lo)/(4×S_t)     # 绝对带转比率域（启动锚）
  # 正式口径: 基差历史库积累 ≥180 日后，改用 dom_basis_rate 序列直接估计 μ̂/σ̂
  # （futures_spot_price_daily 每行含 dom_basis_rate 字段，PIT 采集，见 t4 GA-6/F7）
  z_t = (br_t − μ̂)/σ̂
  signal = +1 if z_t ≤ −1.5 ; = −1 if z_t ≥ +1.5 ; = 0 其他
  F_target = S_t × (1 − μ̂)        # 基差回归 180 日中枢（比率域 μ̂）时对应的期货价（模型导出目标）
  ```
- **策略**:
  - 方向: z≤−1.5 → 多期货腿；z≥+1.5 → 空期货腿（现货不可交易，不做现货腿）。
  - 入场: T 日收盘 br 触发 + 现货质量门通过（见数据依赖）+ `|z|` 未处于加速走扩段（连续 3 日 |z| 递增 → 等待企稳）。
  - 止损: ① br 继续反向走扩 0.5σ̂（信号强化失败）；② 价格 1.5×ATR5 反向。先到先平。
  - 目标定价（模型导出）: `F_target = S_t × (1 − μ̂)`，S_t 取触发日现货价；达到目标或 20 日时间退出，先到先平。禁止引用 FinCoT 概率锥/报告目标价。
  - 逼仓保护: 距交割月 < 20 个交易日的合约不交易（换月至次主力）。
- **数据依赖**:
  - `futures_spot_price_daily(start,end,vars_list)` — 实测 20260801–27 返回 57 行（生意社现货，2011 年起，字段含 dom_basis_rate）；历史回测直接可用。
  - `futures_spot_price_previous(date)` — 实测 54 品种，含 180 日基差最高/最低/平均（分布锚免自建）。
  - 行情腿: `data/daily/{SYM}0.json`。
  - **现货质量门（必须）**: 生意社现货为挂牌价，存在粘性品种；30 日零变动占比 > 40% 的品种剔除出可交易集（防"现货粘性伪造回归"），仅保留观察。逐品种质量报告交 t4。
- **证伪测试**:
  - (a) z 触发后 20 日"基差向 μ̂ 方向收敛"命中率 < 55% → 证伪 F1；
  - (b) 触发后 20 日期货端收益（扣除 0.07% 成本）组合夏普 < 0.5 → 停用；
  - (c) F2 不对称性检验: 深贴水端与深升水端收益符号不对称性不显著 → 双侧规则改为对称（模型修订，不改变证伪门槛）。
- **已知反面证据**: 2022 伦镍逼仓、2024 氧化铝逼仓段——基差极端但期货继续贴水走扩，止损必须硬执行；生意社现货与真实成交价偏离的品种（如部分化工品挂牌价长期不动）即使通过质量门也需降权。
- **证据来源**: Kaldor, N. (1939), "Speculation and Economic Stability", RES — https://doi.org/10.2307/2967593 ；Fama & French (1987), "Commodity Futures Prices: Some Evidence on Forecast Power, Premiums, and the Theory of Storage", Journal of Business — https://www.jstor.org/stable/2352882 ；Boons & Prado (2019), "Basis-Momentum", Journal of Finance — https://onlinelibrary.wiley.com/doi/10.1111/jofi.12808
- **成熟度**: B（理论 A 级 + 数据可立即回测）
- **与 FinCoT 边界**: 目标价仅由上式导出；FinCoT 方向冲突 → 观察。

### FS-03 月差/期限结构展期收益

- **优先级**: P0（合约级数据与采集器均已有）
- **适用品种**: 有 ≥2 个活跃合约的品种；优先 黑色（RB/HC/I/J/JM 主力-次主力）、农产品（M/RM 1-5、5-9）、能化（TA/MA/EG/PP/EB 主力-次主力）；贵金属/航运弱信号慎用（沿用 v1 CS-01 判断）。
- **核心理论（可证伪命题）**:
  - F1: 期限结构斜率（近远月价差率）排序对未来 20 日超额收益有单调预测力（Szymanowska et al. 2014 实证；back 结构 → 多头展期收益为正）。
  - F2: 极端价差分位后价差本身向 120 日中枢回归（展期拥挤与库存驱动的平坦化）。
- **市场模型**:
  ```
  sp_t  = (F1_t − F2_t)/F1_t            # F1=近月活跃合约, F2=次主力或远月活跃
  p_t   = Rank(sp_t | 过去120个交易日)    # 结构分位
  z_t   = (sp_t − μ̂_120)/σ̂_120          # 价差回归 z（策略 B）
  signal_A = +1 if p_t ≥ 0.90 ; = −1 if p_t ≤ 0.10    # 单边方向
  F1_target = F2_t + F1_t × μ̂_120      # 模型导出: 价差回归中枢时 F1 的隐含价（假定 F2 不变）
  ```
- **策略**:
  - 策略 A（单边，低资金占用）: p≥0.90（back 极端）且 `close ≥ MA20` → 多 F1；p≤0.10 且 `close ≤ MA20` → 空 F1。止损 1.5×ATR5(F1)；目标 `F1_target`；20 日时间退出。
  - 策略 B（双腿价差回归，高资金占用）: |z|≥2 → 价差回归入场（z>0: 空 F1/多 F2；z<0: 反向）；目标 z→0 双边平；止损 |z| 反向扩 0.5。仅限双腿流动性双高的品种对，双倍保证金与双倍成本（0.14%）。
  - 展期保护: F1 距最后交易日 < 20 日时停止新开仓。
- **数据依赖**:
  - 合约级日线: `futures_zh_daily_sina(symbol=RB2610)` — 实测 213 行含 `hold`；sina 限流（~80 请求/小时）→ 复用 `collector/futures-term-structure.py`（已含退避与缓存）。
  - 报告管线已在采集 FinCoT 证据包 `term_structure.{near,main,far,spread_pct}`（单日快照），历史月差序列需按日批量补采（新增采集器，挂增量缓存）。
  - 行情腿: `data/daily/{SYM}0.json`。
- **证伪测试**:
  - (a) 按 p_t 五等分组，20 日收益单调性 Spearman 不显著，或 top−bottom 组合夏普 < 0.4 → 证伪 F1；
  - (b) 策略 B: |z|≥2 触发后 20 日回归命中率 < 55% → 证伪 F2；
  - (c) 品种级: 近月合约日成交量 < 主力 20% 的品种对剔除（流动性门）。
- **已知反面证据**: 国内商品活跃月为 1/5/9(10)，近月合约流动性差，价差腿滑点可能吞噬信号；2016 铁矿 09、2021 焦煤逼仓段价差结构失真——策略库实现时加"近月持仓 > 阈值 + 距交割 >20 日"双门。
- **证据来源**: Szymanowska, De Roon, Nijman & Van Den Goorbergh (2014), "An Anatomy of Commodity Futures Risk Premia", JF — https://onlinelibrary.wiley.com/doi/abs/10.1111/jofi.12096 ；Gorton, Hayashi & Rouwenhorst (2007), NBER WP 13249 — https://www.nber.org/papers/w13249
- **成熟度**: B+（学术 20 年 + 仓库已有采集器）
- **与 FinCoT 边界**: 复用 term_structure 证据包仅作数据输入；定价由上式导出。

### FS-04 黑色产业链利润分位（利润→开工→供需再平衡）

- **优先级**: P0-conditional（需 full-history 补齐 250d 标定窗口；初期 120d 窗口降级运行）
- **适用品种**: 钢厂利润（RB × I × J × HC）、焦化利润（J × JM）；螺矿比（RB/I）作为利润压缩代理可并入。
- **核心理论（可证伪命题）**:
  - F1: 钢厂利润代理 z-score 极端亏损（z≤−2）后，未来 40 日利润向中枢回归，且回归主要由产品端（RB）弹性驱动（减产 → 成材供给收缩 → 成材价格修复），而非原料端同步下行。
  - F2: 利润极端高（z≥+2）后，复产/提产 → 成材供给释放 → 利润与成材价格回落。
  - 前提: 利润→开工传导链未被政策打断（见已知反面证据）。
- **市场模型**:
  ```
  π_t   = P_RB,t − (β̂1×P_I,t + β̂2×P_J,t)        # 钢厂利润代理（残差形式）
  标定: OLS  P_RB = α + β1 P_I + β2 P_J（样本内 2016–2026，日频），π = 残差；
        先验权重 (1.6, 0.5)（行业通行口径）仅作初始值，标定后冻结参数。
  z_t   = (π_t − μ̂_250)/σ̂_250
  signal = +1 if z_t ≤ −2 ; = −1 if z_t ≥ +2 ; = 0 其他
  P_RB,target = P_RB,t − z_t × σ̂_250               # 残差向均值回归的模型导出目标价
  焦化利润: πJ_t = P_J,t − 1.33×P_JM,t（同构模型，方向对称）
  ```
- **策略**:
  - 方向: z≤−2 → 多 RB（或 RB 多 / (β̂1·I + β̂2·J) 空 组合，容量允许时）；z≥+2 → 空 RB；焦化: πJ 极端 → 对应 J 单边或 J/JM 价差。
  - 入场: T 日收盘触发 + RB `close ≥ MA20`（多侧确认）。
  - 止损: ① z 反向扩 0.5；② RB 1.5×ATR5。先到先平。
  - 目标定价（模型导出）: `P_RB,target = P_RB,t − z_t × σ̂_250`（利润残差归零对应的成材价）；40 日时间退出。
  - 政策过滤: FS-09 政策日历中"粗钢产量调控/能耗双控"类事件生效期 → 暂停新开仓（传导链被政策接管，模型前提不成立）。
- **数据依赖**:
  - 全为价格数据: `data/daily/{RB0,I0,J0,JM0,HC0}.json`（RB0 已有 500 行；I/J/JM/HC 深度需 `research/backtest/full-history-collector.cjs` 补至 ≥3 年）。
  - 无需付费利润数据——真实钢厂利润（含原料现货成本、运费、加工费）依赖 Mysteel/钢联 → 剔除（§4 X-02），策略只用价格代理并如实声明口径。
- **证伪测试**:
  - (a) z 极端后 40 日 π 回归（|π_40 − μ̂| < |π_0 − μ̂|/2）概率 ≤ 55% → 证伪 F1/F2；
  - (b) 多 RB 单边策略扣成本夏普 < 0.5 → 停用；
  - (c) 归因检验: 回归由原料腿驱动（RB 亏损而 I/J 上涨）的样本占比 > 40% → 单边改双腿结构；
  - (d) 政策窗口（2016–2017 供给侧、2021 粗钢压减、2025 粗钢产量调控）内表现显著劣于全样本 → 政策过滤层为必装组件。
- **已知反面证据**: 2021H2 焦煤暴涨——焦化利润深亏持续 6+ 月不修复（供给刚性+政策），均值回归时滞风险；2014–2015 需求坍塌段，成本随矿价同步下移，"成本支撑"失效——策略库必须写入"利润分位 ≠ 时间反转信号"。
- **证据来源**: Pindyck, R. (2001), "The Dynamics of Commodity Spot and Futures Markets: A Primer", Energy Journal — https://www.jstor.org/stable/41322964 ；国投期货螺矿比套利案例（沿用 v1 链接）— https://www.hgwm.com/hyzx/show/id/1858.html
- **成熟度**: B（行业体系成熟，仓库未直接验证）
- **与 FinCoT 边界**: 报告驱动文本中"钢厂亏损/减产"表述不构成入场依据；入场仅由 z 阈值触发。

### FS-05 农产品压榨/替代价差回归

- **优先级**: P0-conditional（需 full-history 做协整标定）
- **适用品种对**: M−RM（蛋白替代）、Y−M（油粕比）、Y−P（豆棕价差）、OI−Y（菜豆油价差）、C−CS（玉米-淀粉加工价差）
- **核心理论（可证伪命题）**:
  - F1: 替代需求与压榨经济性使上述价差存在长期均衡（协整）；偏离均衡后 20 日内回归，回归由"高估腿回落"与"低估腿回升"共同驱动。
  - F2: 政策/贸易结构变化（进口禁令、反倾销、收抛储）会造成价差中枢**永久性迁移**；迁移后旧中枢的回归信号失效（结构断裂必须先于交易被识别）。
- **市场模型**:
  ```
  协整:  P_1,t = α̂ + β̂ P_2,t + e_t        # Engle-Granger 两步法, 滚动250d估计, 冻结后使用
  z_t   = (e_t − μ̂_e)/σ̂_e
  signal = +1 if z_t ≥ 2 (空腿1/多腿2) ; = −1 if z_t ≤ −2 (反向) ; = 0 其他
  结构断裂门: 最近 60d 残差 ADF p > 0.10 或 β̂ 变化 > 2σ̂_β → 该对停用（中枢迁移中）
  ```
- **策略**:
  - 方向: 双腿回归，按 e 符号定多空（e>0: 腿1高估 → 空腿1/多腿2）。
  - 入场: T 日收盘 |z|≥2 + 结构断裂门通过 + 两腿距交割 >20 日。
  - 止损: |z| 反向扩 0.5 或触 3σ̂；单腿逼仓（近月持仓异常）→ 全平。
  - 目标定价（模型导出）: z→0 双边平（价差回归 μ̂_e，即 e 的模型均衡值；双腿目标价 = 各自价格 ± β̂/(1+β̂) × 半价差偏离）。
  - 时间退出: 20 个交易日（与 F1 的「20 日内回归」时窗一致；t8 审查 F-5 补充——价差 20 日未回归即视为信号失效，平仓重估，不得无限期持有）。
  - 事件暂停: FS-09 政策日历中该品种对的贸易/储备事件生效期 → 暂停新开仓。
- **数据依赖**: `data/daily/{M0,RM0,Y0,P0,OI0,C0,CS0}.json`（现有 2y；full-history 补至 ≥5 年后启用正式标定；初期降级运行）。
- **证伪测试**:
  - (a) 滚动协整通过率 < 70% 的品种对 → 剔除该对；
  - (b) 策略组合扣成本（双腿 0.14%）夏普 < 0.5 或回归命中 < 55% → 停用；
  - (c) M−RM 专项: 2019 菜籽进口政策、2024-09-09 加拿大油菜籽反倾销立案调查（商务部 2024 年第 37 号；原记 2023 系笔误，以 GA-7 日历实证为准）两段结构断裂若未被断裂门捕捉（回测中该段出现 >2 次 3σ 止损）→ 断裂门参数修订，修订后仍不达标 → 该对永久停用（已知反面证据必须写入策略库）。
- **已知反面证据**: 2019 M−RM 价差中枢永久上移，均值回归策略该段大亏；Y−P 受印尼棕榈油出口政策频繁冲击，非平稳段多——豆棕价差列为低置信品种对，仅断裂门通过率连续 90 日 100% 时才允许交易。
- **证据来源**: Gatev, Goetzmann & Rouwenhorst (2006), "Pairs Trading", RFS — https://academic.oup.com/rfs/article-abstract/19/3/797/1646694 ；Engle & Granger (1987), "Co-integration and Error Correction", Econometrica — https://www.jstor.org/stable/1913236
- **成熟度**: B（范式成熟，国内品种对样本内验证待做）
- **与 FinCoT 边界**: 价差回归不引用单品种 FinCoT 方向（两条 FinCoT 结论拼接 = 违反对称性原则）。

### FS-06 库存×基差二维象限（供需状态格点）

- **优先级**: P0（= FS-01 ∩ FS-02 的交集品种；数据同两者）
- **适用品种**: 库存∩基差∩日线三源交集（§1.3），重点 RB HC I J JM / M Y RM OI / TA MA EG PP V EB SA FG UR / NI SN SS SP RU FU BU
- **核心理论（可证伪命题）**:
  - F1: 库存与基差是供需状态的**正交代理**（库存=供给存量，基差=边际紧松）；两者联合的四象限对未来 20 日收益有显著排序: `LL（低库存+现货强升水）> 中间象限 > HH（高库存+期货强升水）`。
  - F2: LL 象限多头与 HH 象限空头是唯一可交易象限；混合象限（HL 高库存+现货升水=挤仓风险段、LH 低库存+期货升水=预期修复段）不可交易。
- **市场模型**:
  ```
  LL: inv_pct_t ≤ 0.2 且 z_br,t ≤ −1.5   → 强多 (signal=+1)
  HH: inv_pct_t ≥ 0.8 且 z_br,t ≥ +1.5   → 强空 (signal=−1)
  其他: signal=0（观望）
  target_LL = min( FS-01目标, FS-02目标 )   # 双模型导出, 取先到者（保守原则）
  target_HH = max( FS-01目标, FS-02目标 )
  ```
  （联合模型为显式 AND 门: 两信号须同一交易日收盘同时成立，禁止跨日拼接。）
- **策略**:
  - 方向: LL → 多期货；HH → 空期货。
  - 入场: 两信号同日成立 + 板块过滤通过（`data/sector/{sector}.json` 当日 `advanceRatio1d ≥ 50%` 且与方向一致——板块广度只作过滤，不参与定价）。
  - 止损: ① 任一维退出极端区（inv_pct 回到 [0.3,0.7] 或 |z_br| < 1.0）；② 1.5×ATR5。先到先平。
  - 目标定价: 双模型目标的保守者（见上式）；20 日时间退出。
- **数据依赖**: 同 FS-01 + FS-02（`futures_inventory_em` 增量库、`futures_spot_price_daily/_previous`、`data/daily`、`data/sector`）。
- **证伪测试**:
  - (a) 四象限 20 日收益排序检验（Jonckheere-Terpstra）p ≥ 0.05 → 证伪 F1；
  - (b) LL 多头 / HH 空头命中率 < 60% 或扣成本夏普 < 0.6 → 停用；
  - (c) 时间切分: 后 30% 样本（样本外）不显著 → 降级 P1。
- **已知反面证据**: 2023 纯碱"高库存+高基差率"段（供给扰动使 HH 定义失效）→ 象限策略必须叠加 FS-09 事件过滤；挤仓品种（镍 2022）在任何象限都禁止空头。
- **证据来源**: 同 FS-01/FS-02 文献；国内卖方通行框架（库存+基差双代理刻画供需）为行业实践。
- **成熟度**: C（联合框架假设性，需验证后升级）
- **与 FinCoT 边界**: 象限判定全部来自基本面数据字段，不引用 FinCoT 文本结论。

### FS-07 季节性窗口（日历供需周期）

- **优先级**: P0-conditional（前置: full-history-collector 补齐 ≥8 年主力连续日线）
- **适用品种**: 黑色（RB/HC/I/J 开工季）、农产品（M/RM 生长季与水产旺季、P 减产季、SR 春节备货）、能化（MA 秋检旺季、BU 施工季）；SC 类全球定价品种季节性弱 → 不入集（先验弱）。
- **核心理论（可证伪命题）**:
  - F1: 天气/假期/开工/收获构成可重复日历供需周期；某品种某月历史平均超额收益显著 ≠ 0（block bootstrap 1000 次，p<0.05），且该月历史胜率 ≥ 60%。
  - F2: 季节性只在"当年供需结构与历史均值接近"时有效；结构异常年（政策/极端天气）季节模式失效。
- **市场模型**:
  ```
  r̄_m = 该月历史平均收益（≥8年, 主力连续比率拼接, 剔除结构异常年）
  bootstrap: p(r̄_m ≤ 0) < 0.05 且 胜率_m ≥ 60% → 月 m 为有效季节窗口
  signal = 方向(r̄_m) 仅当 t ∈ 窗口 且 close_t ≥ MA20（多窗口）/ ≤ MA20（空窗口）
  P_target = P_entry × (1 + 0.8 × r̄_m)   # 模型导出: 季节模型自身的历史窗口收益 × 80% 折扣
  ```
- **策略**:
  - 方向: 有效窗口的方向。
  - 入场: 窗口首个交易日收盘确认（MA20 过滤）；窗口开始前 20 日累计涨跌幅已超历史窗口均值 +1σ → 该年跳过（预期透支）。
  - 止损: 1.5×ATR5。
  - 目标定价: `P_target = P_entry × (1 + 0.8 × r̄_m)`（80% 折扣防透支）；窗口结束强制退出。
  - 叠加条件: 与 FS-01 库存分位同向时才全仓，反向时半仓（季节与库存状态冲突说明当年结构异常）。
- **数据依赖**: 主力连续 ≥8 年日线 → `research/backtest/full-history-collector.cjs`（工具已存在，运行即可）；`data/daily` 现深度 2y 不足，必须先扩展。比率拼接复权逻辑用 `research/backtest/` 现有 lib（cache-slicer / shared-backtest-lib）。
- **证伪测试**:
  - (a) bootstrap 不显著的月份从日历删除（显著性不过 = 不算季节）；
  - (b) 全部有效窗口组合扣成本夏普 < 0.5 → 整体证伪；
  - (c) 有效窗口品种数 < 3 → 降级 P1（季节性仅作过滤层，不作独立策略）。
- **已知反面证据**: 2021 黑色"金九银十"彻底失效（能耗双控+煤价暴涨覆盖季节逻辑）——季节策略永远不能单独使用（v1 CS-02 结论沿用: 单独使用胜率不足）。
- **证据来源**: Sorensen, C. (2002), "Modeling seasonality in agricultural commodity futures", Journal of Futures Markets — https://onlinelibrary.wiley.com/doi/10.1002/fut.10017 ；v1 `strategies/research/category-strategies.md` §CS-02 链接。
- **成熟度**: B−（行业惯例；本仓库未验证）
- **与 FinCoT 边界**: 季节窗口日历为模型自有输出；FinCoT 不参与日历生成。

### FS-08 能化成本传导误差修正（原油→化工品）

- **优先级**: P0-conditional（需 full-history 做协整/ECM 标定）
- **适用品种对**: SC→TA、SC→EG（油头工艺，弱）、SC→PP、SC→L、SC→EB、SC→BU、SC→FU、SC→PG；PX→TA 亦可。**MA 不入集**（煤化工，成本锚是煤而非油——保持模型内一致性，煤价无免费日频源）。
- **核心理论（可证伪命题）**:
  - F1: 原油是油化工品种的成本锚，产品价与 SC 价存在协整；短期偏离通过产品端以误差修正机制回归（ECM 修正系数 γ 显著 < 0）。
  - F2: 产品端偏离成本锚的 z-score |z|≥2 后，20 日内产品价格向成本锚回归；回归由产品端承担（SC 端受外盘主导，不构成可交易的回归腿）。
- **市场模型**:
  ```
  协整:  P_prod,t = α̂ + β̂ P_SC,t + e_t      # 滚动250d, 冻结参数
  ECM:   ΔP_prod,t = γ × e_{t−1} + Σ β_j ΔP_SC,t−j + ε_t      # γ < 0 显著为启用前提
  z_t   = (e_t − μ̂_e)/σ̂_e
  signal = −1 if z_t ≥ +2 (产品高估 → 空产品) ; = +1 if z_t ≤ −2 (产品低估 → 多产品)
  P_target = α̂ + β̂ × P_SC,t + μ̂_e          # 误差归零的模型导出产品目标价
  ```
- **策略**:
  - 方向: 只做产品腿（不裸做 SC 腿: SC 无库存/基差数据，且原油波动受外盘主导，与模型回归假设不符）。
  - 入场: T 日收盘 |z|≥2 + γ 显著性门通过（最近 250d ECM 估计 γ 的 p<0.05）+ 产品 `close ≥ MA20`（多侧）。
  - 止损: ① e 反向扩 0.5σ̂_e；② 产品 1.5×ATR5。先到先平。
  - 目标定价: `P_target = α̂ + β̂ × P_SC,t + μ̂_e`；20 日时间退出。
  - 隔夜保护: SC 夜盘与外盘跳空导致产品次日开盘跳空——开盘跳空 > 1×ATR5 的交易日不新开仓；已持仓位在跳空反向时按止损硬执行。
- **数据依赖**: `data/daily/{SC0,TA0,EG0,PP0,L0,EB0,BU0,FU0,PG0,PX0}.json`（深度不齐，MA0 仅 61 行类问题需 full-history 补齐；标定需 ≥750 日）。
- **证伪测试**:
  - (a) 残差 ADF p>0.05（无协整）或 γ ≥ 0（无误差修正）→ 该品种对证伪；
  - (b) 策略扣成本夏普 < 0.5 → 停用；
  - (c) 隔夜跳空亏损占策略总亏损 > 30% → 增加隔夜过滤（半仓/仅日内评估），修订后仍 >30% → 停用。
- **已知反面证据**: 2022 俄乌冲突段 SC 暴涨而化工品跟涨滞后、幅度不足——ECM 长时偏离（z 极端持续数周），模型在该类外生冲击段必然止损；须与 FS-09 事件日历联动暂停。
- **证据来源**: Engle & Granger (1987) 同 FS-05 链接；裂解价差文献（沿用 v1 CS-04 链接）— https://www.sciencedirect.com/science/article/abs/pii/S0264999311002586
- **成熟度**: C（ECM 范式成熟，国内油化工品种对未验证）
- **与 FinCoT 边界**: 定价仅由 ECM 方程导出。

### FS-09 政策/事件驱动（收抛储·进口·限产·监管）

- **优先级**: P0-conditional（模型可回测；前置: 人工维护政策日历 ≥20 个历史事件样本）
- **适用品种**: 全品种（政策敏感度排序: 黑色限产 > 农产品收抛储/进口 > 能化监管/出口配额）
- **核心理论（可证伪命题）**:
  - F1: 供给类政策事件使供给曲线平移，价格出现跳跃 + 衰减: 供给收缩类（限产/进口限制/收储）事件后 5 个交易日累计超额收益 CAR_5 显著 > 0；供给扩张类（抛储/放储/进口放开）CAR_5 < 0。
  - F2: 事件效应在公告后 5 日内完成大部分（CAR 前 3 日 ≥ 80% 总效应则"追涨不可行"——事件只可做布局/首日确认，不可追第 4 日）。
  - F3: 公告前 3 日已有显著 CAR（|CAR_pre| > 1σ 日收益）→ 信息已泄露，事件不可交易（剔除，不是交易机会）。
- **市场模型**:
  ```
  AR_t = r_t − r̂_t            # 基准 r̂_t: 品种前20日均收益 或 data/sector 板块指数收益
  CAR_5 = Σ_{t=0..4} AR_t     # 公告日为 t=0（公告日收盘确认）
  E[AR_1 | 分类c, |ΔP_0| < 1×ATR5] = 方向(c) × 历史同类事件 CAR_5 均值 × 0.7   # 模型导出目标
  ```
- **策略**:
  - 方向: 由事件分类决定（供给收缩 → 多；供给扩张 → 空；需求类政策 → 方向不定，仅观察）。
  - 入场: 公告日收盘确认 + 当日 |ΔP| < 1×ATR5（未一步到位）→ 次日开盘同向入场；若当日 |ΔP| ≥ 1×ATR5（跳空透支）→ 放弃。
  - 止损: 1×ATR5（事件失效即止损: 政策未落地、超预期反向、监管转向）。
  - 目标定价: `P_target = P_entry + 方向 × 历史同类 CAR_5 均值 × 0.7`；持有 ≤5 日。
  - 事件集要求: 每个事件留档 `{date, product, category(供给收缩/供给扩张/需求/监管), title, source_url, 落地状态}`；分类与方向映射先验表在回测中检验。
- **数据依赖**: 政策日历 = 公开信息人工维护 YAML（发改委/商务部/海关/交易所公告，URL 留档，无免费结构化政策库）；行情 `data/daily`；基准 `data/sector`。
- **证伪测试**:
  - (a) 某分类事件 CAR_5 符号正确率 < 60% → 该分类从策略删除；
  - (b) 事件次日跳空占比 > 50%（无法以合理价格入场）→ 不可交易，降级 P1；
  - (c) 公告前 3 日 |CAR_pre| > 1σ 占比 > 30% → 该事件源信息泄露严重，整体停用。
- **已知反面证据**: 2021 发改委煤价监管系列——政策意图明确但价格先涨停后跌停，方向交易在极端波动段失效；2010–2012 棉花抛储段方向效应不显著（市场已充分预期）。
- **证据来源**: MacKinlay, A.C. (1997), "Event Studies in Economics and Finance", JEL — https://www.jstor.org/stable/2729691
- **成熟度**: C（方法论成熟，国内期货事件集未建立）
- **与 FinCoT 边界**: 事件日历独立于 FinCoT；FinCoT 驱动文本提及政策不构成事件（必须日历留档才算）。
