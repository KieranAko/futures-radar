# 可执行交易 Playbook 库（execution-playbooks）

> **定位**：资深期货交易员视角的"可落地执行"策略模板库。每个 playbook 只回答一个问题：
> 在什么条件下、以什么价格、做什么动作、错了怎么退出。规则全部可量化、可证伪。
>
> **产出方**：trader（资深期货交易员）| **上游**：futures-radar 日报数据字段 | **下游**：strategy-architect（策略库整合 t5、匹配引擎 t8、报告板块 t9）
>
> ⚠️ **免责声明**：本文件为策略研究方法论，不构成投资建议，不执行真实交易。
> 所有"内部证据"均为 futures-radar 仓库的**样本内探索性回测**（见 `futures-radar/research/archive/backtest-reports/EXECUTIVE-SUMMARY.md` 的正式声明），
> 不具备样本外预测能力；所有"经典文献"证据描述的是历史市场经验，不代表未来表现。

## 0. 口径定义与通用纪律（所有 playbook 的前置规则）

### 0.1 数据口径（与 futures-radar 报告字段一一对应）

| 符号 | 定义 | 来源 |
|------|------|------|
| T | 信号评估日（日线完整 bar，收盘后口径） | radar 报告 |
| ATR5 | 5 日平均真实波幅 | `probability.json`（atr5 字段） |
| MA20 / MA60 | 20/60 日简单均线 | radar Q2（趋势/脉冲） |
| HV / HV%ile | Yang-Zhang 20 日年化波动率 / 其在近 90 日的分位 | `probability.json` |
| 3d/5d p68 / p95 | HV 概率锥 3/5 日 68%/95% 置信区间 | `probability.json`（cone 字段） |
| ATR 带 | close ± 2×ATR5 | radar「价格区间对比」表 |
| 偏差分析 | \|ATR带宽 − HV95带宽\| ÷ HV95带宽 | radar；<10% 稳定 ✅ / 10-20% 谨慎 ⚠️ / >20% 弃用 ❌ |
| 量比 | 当日成交量 ÷ 近 20 日均量 | radar 原始字段推导 |
| OIΔ | 当日持仓量环比变化 % | radar Q4/Q5 持仓表述 |
| Vol%ile / Vol× / 5dΔ / 方向 / 趋势(vs20/60) | 扫描器 Top10 字段 | radar「Top 10 异动排名」 |
| 涨跌停距离 | 现价距当日涨跌停板 % | radar Q6 |

### 0.2 执行口径

- **信号日与执行日**：所有 playbook 的信号在 T 日收盘评估；执行在 **T+1 开盘**（跳空条件见各 playbook），无日内数据，不提供盘中入场规则。
- **夜盘归属**：夜盘 bar 归属下一交易日（源口径）；隔夜跳空风险按各 playbook 的"跳空放弃/风控条款"处理。
- **成本口径**：往返 ≈0.07%（佣金万三双边 + 滑点万二双边，沿用 `DIRECTION_V2_CLOSURE_REPORT.md` 口径）；保证金按 5%-15% 计。**入场前预筛**：单笔潜在盈利必须 ≥ 3× 往返成本，期望 R ≥ 1.5，否则放弃该交易。
- **R 单位**：1R = 单笔风险金额（入场价到初始止损的距离 × 合约乘数 × 手数）。

### 0.3 头寸与组合纪律（海龟/Van Tharp 体系，按本仓库品种特征调整）

| 规则 | 数值 |
|------|------|
| 单笔风险上限 | 账户权益的 **1%**（保守 0.5%） |
| 手数公式 | `手数 = floor(权益 × 1% ÷ (止损距离点数 × 合约乘数))`，再按交易所限仓与流动性截断 |
| 同板块最大敞口 | 2× 单笔风险（2R） |
| 组合热力上限 | 4R（与雷达 Top 3 对齐，最多并行 3 个品种） |
| 加仓铁律 | 只对浮盈仓位金字塔式加仓；**亏损仓位绝不摊平**；加仓后单品种总风险 ≤ 2R |
| 单日亏损熔断 | 当日亏损达 3% 权益 → 停止新开仓；周回撤 8% → 全部平仓、冷却 5 个交易日复盘 |
| 停板风控 | 现价距涨跌停 < 1×ATR5 → 不开新仓 |
| 跳空风控 | 执行价跳空 > 各 playbook 上限 → 放弃该笔，不追价 |
| 方向标签纪律 | radar 的「方向」只作**过滤**（只在该方向上找入场），**不作为入场理由**——本仓库方向预测已被大样本证伪（`DIRECTION_V2_CLOSURE_REPORT.md`：full acc 50.94% ≈ 硬币，TERMINATE） |

> **头寸示例（RM0 菜粕，20260827 报告数据）**：ATR5=48.60，PB-01 止损 1.5×ATR5≈73 点；合约乘数 10 元/吨 → 单笔风险 730 元/手。权益 10 万元、单笔风险 1% = 1000 元 → 手数 = floor(1000/730) = 1 手。

## 1. PB-01 趋势动量延续（EMA20 斜率 + 20 日新高/新低突破）

**一句话逻辑**：只在已确立的趋势方向上，等价格用"突破新高 + 放量"证明趋势仍在加速时入场。本仓库样本内唯一正向验证的方向型模型。

| 参数 | 默认值 |
|------|--------|
| 趋势前置（多） | close > MA20 且 EMA20 斜率 ≥ +0.3%/日 |
| 趋势前置（空） | close < MA20 且 EMA20 斜率 ≤ −0.3%/日 |
| 入场触发 | T 收盘突破近 20 日最高（多）/ 最低（空），且量比 ≥ 1.2 |
| 持仓确认（多） | OIΔ ≥ 0（持仓增或持平） |
| 执行 | T+1 开盘；跳空 > 0.5×ATR5 放弃 |
| 初始止损 | min(入场价 ∓ 1.5×ATR5, 突破前 3 日低/高点 ∓ 0.25×ATR5)，取更近者 |
| 目标 T1 | 2R 平 50% |
| 目标 T2 | 3R 或 3d p95 上/下沿，取先到者；余仓 2×ATR5 移动止损 |
| 时间止损 | 持有满 10 个交易日未触及 T1 → 全平 |
| 加仓 | 浮盈 ≥ 1R 且再创 5 日新高/低 → +0.5 单位（止损上移至加仓价 ∓ 1×ATR5）；最多 2 次 |
| 持有 | 2-10 个交易日（日线级） |

**方向适配**：多空完全对称；空头在距涨停 < 1×ATR5 时禁开（逼仓风险，radar Q6 口径）。

**失效条件（可证伪）**：
- 交易级：收盘跌回 20 日高点下方 > 0.5×ATR5（多，空头镜像）→ 次日开盘离场，不等待止损；量比 < 0.8 连续 2 日 → 动能衰竭，次日离场。
- playbook 级：回测样本 ≥ 200 笔时，扣成本胜率 < 35% 或盈利因子 < 1.2 → 停用本参数组。

**证据来源**：
- 内部：`futures-radar/research/archive/backtest-reports/SIMPLE-MOMENTUM-RESULTS.md`（EMA20 严格 17 笔 +1.54%、Sharpe 3.54；放宽 65 笔 +1.21%、Sharpe 3.25 —— **均为样本内探索性结果**）；
- 外部：Moskowitz, Ooi & Pedersen (2012) "Time Series Momentum", *Journal of Financial Economics* 104(2) — 58 个期货品种 12 个月动量显著（DOI: <https://doi.org/10.1016/j.jfineco.2011.11.003>，收录页: <https://research.cbs.dk/da/publications/time-series-momentum/>）；Hurst, Ooi & Pedersen (2017) AQR《A Century of Evidence on Trend-Following Investing》（SSRN: <https://papers.ssrn.com/sol3/papers.cfm?abstract_id=2993026>）。
- **证据级别：A−**（内部样本内正向 + 外部学术文献，但缺样本外验证）。

## 2. PB-02 Donchian 通道突破（海龟式，附本仓库反面证据）

**一句话逻辑**：经典海龟系统——价格突破 N 日通道入场，反向通道离场，2N 止损，0.5N 金字塔加仓。**本仓库样本内初步证伪，未经 ≥200 笔重新验证禁止实盘**（诚实披露见下）。

| 参数 | S1（快） | S2（慢） |
|------|----------|----------|
| 入场（多/空） | T 收盘突破前 **20** 日最高/最低 | T 收盘突破前 **55** 日最高/最低 |
| 离场 | 反向突破前 **10** 日最低/最高 | 反向突破前 **20** 日最低/最高 |
| N（ATR 基准） | ATR20 | ATR20 |
| 初始止损 | 入场价 ∓ **2N**；若 2N 对应风险 > 2% 权益 → 减手数至 ≤2% | 同左 |
| 加仓 | 浮盈每 +0.5N 加 1 单位，最多 **4** 单位；每单位止损同步上移 0.5N | 同左 |
| 追踪止损 | 浮盈 ≥ 3N 后启用 2N 追踪 | 同左 |
| 执行 | T+1 开盘；跳空 > 0.5N 放弃 | 同左 |
| 持有 | 5-30 个交易日 | 20-60 个交易日 |

**方向适配**：多空对称；空头距涨停 < 1×ATR5 禁开。

**失效条件（可证伪）**：
- 交易级：收盘回到通道内 > 0.5N → 次日开盘离场。
- playbook 级：**本仓库样本内已出现反面证据**——Donchian 邻近度方向预测 5 笔、准确率 20.0%、均值 −1.36%（`SIMPLE-MOMENTUM-RESULTS.md`，"High-volatility commodities don't respect Donchian channels"）。**因此本 playbook 的默认状态是"停用"，只有在本仓库回测框架下 ≥200 笔、95% CI 不含 0 的验证通过后才可启用**（验证口径见 §10）。

**证据来源**：
- 外部：Curtis Faith《Way of the Turtle》(2007)（专著）；原版海龟法则（1983，Richard Dennis 组）；海龟系统金字塔仓位管理的公开实现参考：<https://github.com/Rors78/turtle-bot>。
- 内部（反面）：`SIMPLE-MOMENTUM-RESULTS.md`（Donchian ❌）。
- **证据级别：B−**（经典但本样本初步证伪，需重新验证）。

## 3. PB-03 回踩趋势延续（MA20/MA60 对齐 + 确认 K 线）

**一句话逻辑**：趋势中不追突破，等回踩至 MA20 支撑带出现"收盘反包"确认后再入场——入场更接近止损，R 赔率更优。

| 参数 | 默认值 |
|------|--------|
| 趋势前置（多） | close > MA20 且 MA20 > MA60（或 MA20 斜率向上）；空头镜像 |
| 回踩条件（多） | 盘中/收盘触及 MA20 ± 0.25×ATR5 区间；量比 0.8-1.5（缩量回踩为佳） |
| 确认 K 线（多） | T 收盘 > T−1 最高价（空头：T 收盘 < T−1 最低价） |
| 执行 | T+1 开盘；跳空 > 0.75×ATR5 放弃 |
| 初始止损 | 回踩最低价（多）− 0.25×ATR5；**且止损距离必须 ≤ 1.5R**，否则放弃该笔 |
| 目标 T1 | 前期波段高点/低点 或 3d p68 上/下沿，取先到者，平 50% |
| 目标 T2 | 2R-3R，余仓 1×ATR5 移动止损 |
| 加仓 | 突破 T1 且量比 ≥ 1.2 → +0.5 单位（止损上移 1×ATR5）；最多 1 次 |
| 时间止损 | 持有满 8 个交易日未触及 T1 → 全平 |
| 持有 | 3-8 个交易日（日线级） |

**方向适配**：多空对称；空头反抽要求 OIΔ ≤ +2%（持仓不增，规避逼仓）；多头回踩要求 OIΔ ≥ −2%（持仓不塌）。

**失效条件（可证伪）**：
- 交易级：收盘 < MA20 − 0.5×ATR5 且量比 ≥ 1.5（放量破位）→ 次日开盘离场；空头镜像。
- playbook 级：连续 10 笔止损，或回测 200 笔盈利因子 < 1.2 → 停用。

**证据来源**：
- 外部：Linda Raschke & Laurence Connors《Street Smarts》(1996)（专著：回踩入场与 "Holy Grail" 形态——ADX < 30、20 日低点入场、前低止损、20 日高点离场；形态参数社区实现参考：<https://il.tradingview.com/script/hawl3ybg-Holy-Grail-Setup-with-Confidence-Opacity/>）；Edwards & Magee《Technical Analysis of Stock Trends》（专著：趋势线回踩经典）。
- 内部：radar Q2「趋势/脉冲」字段直接给出 MA20/MA60 对齐状态（如 RM0：+5.7%/+6.1% 趋势对齐）。
- **证据级别：B**（经典文献与行业通行，本仓库未直接回测）。

## 4. PB-04 波动率压缩 → 扩张爆发（NR7/低 HV 分位 + 放量方向确认）

**一句话逻辑**：波动率压缩（HV%ile 低 / 区间收窄）后第一根放量扩张 K 线往往启动短期趋势——不做方向预测，只做"扩张方向跟随"。

| 参数 | 默认值 |
|------|--------|
| 压缩前置 | HV%ile ≤ 30，或 NR7（T 日 TR 为近 7 日最小） |
| 扩张触发日 | T 日 TR ≥ 2× 近 5 日平均 TR，且收盘位于当日区间上 20%（多）/ 下 20%（空），量比 ≥ 1.5 |
| 执行 | T+1 开盘（跳空 ≤ 0.5×ATR5）或 T+1 收盘再确认、T+2 开盘（保守档） |
| 初始止损 | min(入场价 ∓ 1×ATR5, 扩张日区间中点)，取更近者 |
| 目标 T1 | 2R 平 50% |
| 目标 T2 | 3d p95 上/下沿，先到者；余仓 1×ATR5 移动止损 |
| 时间止损 | 持有满 5 个交易日未触及 T1 → 全平 |
| 加仓 | 浮盈 ≥ 1R 且连续 2 日收盘同向 → +0.5 单位；最多 1 次 |
| 持有 | 2-5 个交易日（爆发短促，见好就收） |

**方向适配**：压缩期方向不可预判 → 只做扩张方向跟随，**禁止在扩张日反向抄底/摸顶**；多空对称。

**失效条件（可证伪）**：
- 交易级：收盘回到扩张日区间内 50% 以下（多，空头镜像）→ 次日开盘离场。
- playbook 级：回测 200 笔扣成本胜率 < 40% → 停用。

**证据来源**：
- 外部：Toby Crabel《Day Trading with Short Term Price Patterns and Opening Range Breakout》(1990)（压缩/扩张与 NR7）；Bollinger (2002)《Bollinger on Bollinger Bands》（带宽挤压）。
- 内部：radar 扫描器 Vol%ile / Vol× 字段可直接参数化压缩-扩张状态（如 20260827 样本 EG0 Vol× 1.71、Vol%ile 86）。
- **证据级别：C**（假设性，未回测；需按 §10 验证）。

## 5. PB-05 均值回归（2×ATR 极值偏离 MA20 的逆向交易）

**一句话逻辑**：价格超出 MA20 ± 2×ATR5 带（radar 报告现成的 ATR 通道）属于统计极端，在无新驱动、波动率未失控时逆向回归均线。**内部证据提示：本仓库高波动品种动量 > 均值回归，本 playbook 只建议用于 HV%ile 低-中位品种**。

| 参数 | 默认值 |
|------|--------|
| 入场前置 | 无当日新驱动新闻（radar Q1 驱动为空/旧）；HV%ile ≤ 85；OIΔ 绝对值 ≤ 5% |
| 入场触发（多） | T 收盘 ≤ MA20 − 2×ATR5，且当日未触及跌停；空头镜像 |
| 执行 | T+1 开盘；跳空 > 0.5×ATR5 放弃（跳空加剧 = 极端加深，禁止接刀） |
| 初始止损 | min(入场价 ∓ 1×ATR5, 极值价 ∓ 0.5×ATR5)，取更近者 |
| 目标 T1 | MA20（平 50%） |
| 目标 T2 | 2R（全平） |
| 时间止损 | 持有满 5 个交易日未触及 T1 → 全平 |
| 加仓 | **禁止加仓**（逆势单次仓位）；浮盈 1R 后止损移至成本 |
| 持有 | 1-5 个交易日 |

**方向适配**：多空对称；多头回归附加条件：所在板块当日上涨广度 ≥ 30%（radar 板块表），避免系统性下跌中接刀。

**失效条件（可证伪）**：
- 交易级：盘中/收盘出现新驱动新闻 → 前提破坏，立即离场；HV%ile 升破 90 → 当日弃用本 playbook。
- playbook 级：回测 200 笔盈利因子 < 1.2，或分品种后发现 HV%ile ≥ 60 子样本亏损 → 缩窄适用范围至 HV%ile ≤ 60。

**证据来源**：
- 外部：Connors & Alvarez《Short Term Trading Strategies That Work》(2009)（专著：RSI(2)<5 / >95 逆向，200 日 MA 过滤；方法摘要：<https://chartschool.stockcharts.com/table-of-contents/trading-strategies-and-models/trading-strategies/rsi-2>）；Bollinger (2002)《Bollinger on Bollinger Bands》（专著：±2σ 带约含 88% 收盘价的经验观察）。
- 内部（反面提示）：`SIMPLE-MOMENTUM-RESULTS.md` 结论——高波动商品中简单动量 >> 均值回归/通道逻辑。
- **证据级别：C**（未回测 + 内部存在反向证据提示，仅限低波动子集试验）。

## 6. PB-06 区间/箱体边界交易（低波动率箱体，回归 + 突破双模式）

**一句话逻辑**：低波动率品种在明确箱体内做边界回归；箱体被放量突破则切换为顺势模式（移交 PB-02 管理）。边界逻辑在本仓库有初步反面证据，双模式设计正是为了把"假突破"转成可证伪条件。

| 参数 | 默认值 |
|------|--------|
| 箱体定义 | 近 20 日最高价/最低价构成箱体；HV%ile ≤ 40；箱宽 ≥ 2.5×ATR5；箱体内至少 4 次触及边界 |
| 模式 A 入场（回归） | 触及边界当日收盘仍在箱内 → T+1 反向入场（上沿空 / 下沿多） |
| 模式 B 入场（突破） | T 收盘突破边界且量比 ≥ 1.5 → T+1 顺势入场（移交 PB-02 管理） |
| 执行 | T+1 开盘；跳空 > 0.5×ATR5 放弃 |
| 止损 A | 边界外 0.25×ATR5 |
| 止损 B | 1×ATR5（按 PB-02 可扩至 2N） |
| 目标 A | 对侧边界；入场前必须满足潜在盈利 ≥ 1.5R，否则不做 |
| 目标 B | 箱高 1:1 投影 或 2R，取先到者 |
| 加仓 | A 禁止；B 按 PB-02 金字塔（0.5N、最多 4 单位） |
| 持有 | A：1-4 个交易日；B：5-20 个交易日 |

**方向适配**：A 模式多空对称；B 模式突破方向跟随（禁止预判突破方向）。

**失效条件（可证伪）**：
- 交易级（A）：连续 2 日收盘在箱外 → 区间失效，离场并转 B 模式逻辑。
